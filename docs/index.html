CrabLogic 2.0.0

Визуальное программирование микроконтроллеров ESP32 и ESP32‑C3: рисуете схему из блоков (FBD), программа заливает её на плату по USB или по сети и показывает живые значения на схеме. Плата работает на готовой прошивке-мастере на Rust. Ядро программы тоже написано на Rust.

Что умеет

Схема из блоков

Привычная для FBD раскладка: платы-листы, библиотека блоков справа, проверка схемы (типы, порты, входы без источника, циклы без памяти).

Заливка без компиляции

Прошивка-мастер заливается на плату один раз кнопкой ⬆, ничего собирать не нужно. Листы схемы идут на плату модулями WASM с AOT-ускорением, по USB или по сети (Wi-Fi, Ethernet; пароль проекта). Лист заменяется на ходу, остальные не останавливаются.

Онлайн-отладка

Живые значения на схеме, графики, форсировка сигналов, консоль платы — по USB или по сети. USB приоритетнее сети.

Веб-конструктор

Веб-страница платы с виджетами, графиками и сетевой формой собирается в отдельном конструкторе и хранится в проекте.

Сеть и протоколы

Wi-Fi, Ethernet (W5500, LAN8720), MQTT, Sparkplug B, NTP, Modbus RTU и TCP, веб-страница платы.

Свои блоки

Блоки — это файлы: библиотека расширяется без перекомпиляции, свои блоки и драйверы железа пишутся на Rust или C и работают как WASM. Есть ИИ-помощник, MCP-сервер и симуляция без платы.

Железо и быстрые сигналы

Дисплеи OLED и LCD с меню, быстрые счётчики (PCNT), частота, энкодер, аналоговый выход (DAC), период цикла от 1 до 10 мс.

Надёжность

Детерминированный скан, сторож шага, безопасные состояния выходов при отказе, защита флеша от износа. Аварийный стоп — только аппаратно.

Скриншоты

Быстрый старт

  1. Скачайте CrabLogic.zip со страницы релиза и распакуйте.
  2. Запустите crablogic-editor.exe.
  3. Подключите ESP32 или ESP32‑C3 по USB и один раз залейте мастер кнопкой ⬆.
  4. Нарисуйте схему (или откройте пример «Примеры → pump») и проверьте её: F7.
  5. Залейте модули схемы кнопкой 📦 (по USB или по сети).
  6. Включите отладку кнопкой 🛠 («Проект → Отладка: залить и подключиться») и смотрите живые значения.

Статус

Версия 2.0.0. Windows 10/11 x64; платы ESP32 и ESP32‑C3. Обновление мастера по сети пока не готово (позже, для плат с 8 и 16 МБ флеша): мастер заливается по USB. Программа развивается одним автором, сообщения об ошибках приветствуются в Issues.
