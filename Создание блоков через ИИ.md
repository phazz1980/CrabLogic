# Создание блоков через ИИ

Новый блок можно описать словами: ИИ напишет `block.toml`, модуль `block.wasm` и `docs.md`,
проверит их и положит в `user_library/`. Встроенные блоки (`library/`) ИИ менять не может.

- **Чат в редакторе** и **MCP-сервер** используют команду `create_block_type` (`block.toml`,
  `block.wasm` в base64, `docs.md`): блок проверяется до записи, при ошибках запись откатывается.
- Внешний агент (Claude Code и др.) работает по навыку `skills/crablogic-block/` и проверяет блок
  командой `crablogic block check <папка блока>`.

Код на C++ (`esp32.cpp.tmpl`, `native.cpp`) больше не поддерживается.
