CrabLogic — визуальное программирование ESP32 (FBD). Ядро написано на Rust.

Запуск: crablogic-editor.exe. Папка library должна лежать рядом с exe.

Мастер-прошивка (Rust) лежит в папке firmware\<чип>\: редактор заливает её на плату по USB
кнопкой «Залить мастер-прошивку», а схему — модулями WASM («Залить модули»). Внешних
инструментов для сборки не нужно. Ускорение модулей (AOT) использует wamrc: при первом
использовании он скачивается автоматически.

Примеры схем — в папке examples.

Свой блок или плата с ИИ-помощником (Claude Code, Cursor, Codex): откройте эту папку в нём —
инструкции в skills\, AGENTS.md и CLAUDE.md, исходники блоков — в blocks_src\.
