# Bundled font

`OpenGostTypeB-Regular.ttf` — OpenGost Type B (GOST 2.304 type B drawing font, Latin and Cyrillic),
SIL Open Font License 1.1 (`OFL-OpenGost.txt`). Copyright: Nikita Volchenkov 2011-2012 (Reserved Font
Names "OpenGost Type A" and "OpenGost Type B"), Valek Filippov 2012, Nadeŭka 2026.
Source: https://codeberg.org/nadevko/opengostfonts, release v0.4.0 (file `OpenGostFonts-0.4.0.zip`),
used unmodified. It is embedded in `crablogic-pdf` and used for the schematic sheets
(`crab-schematic`), as GOST IEC 61082-1 5.11 asks for a drawing font (ISO 3098 type B).
