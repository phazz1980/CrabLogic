# Ошибки `crablogic block check` и что делать

Вывод: `ошибка [код]: текст` и строка `→ подсказка`. Код выхода 1, пока есть ошибки; предупреждения
блок не роняют, но перед сдачей их тоже убери.

| Код | Что значит | Как исправить |
| --- | --- | --- |
| `toml` | `block.toml` нет, не читается или не TOML; неизвестный тип порта (`double`, `float32`) | сверь строку и столбец из ошибки; типы портов — только `bool`, `int`, `float` |
| `def` | описание неверно: имя порта с пробелом/точкой/повтором, `type` ≠ имени папки, `default` не того вида или вне `min`/`max`, `when` ссылается на несуществующий параметр | поправь поле, названное в тексте |
| `builtin` | тип занят встроенным блоком (`mul`, `timer_on`…) | другое имя: `type`, папка и `name` в `Cargo.toml` |
| `cpp` | в папке `esp32.cpp.tmpl` или `native.cpp` | код на C++ не поддерживается: перепиши как `block.wasm`, файл C++ удали |
| `no-wasm` | нет `block.wasm` | собери (`build.ps1`) и проверь, что он скопирован в папку блока |
| `wasm` | модуль не подходит: нет экспорта `step`, чужой импорт (`env.*`, WASI), не та сигнатура импорта, таблицы, `memory.grow`, данные больше 32 КБ | см. текст; частые причины ниже |
| `string` | есть порт или параметр `string` | `block.wasm` получает только числа: замени на `int`/`float`/`bool` |
| `schema` | блок не встал в пробную схему (например, параметр `pin` с неподходящим `mode`) | текст называет порт или параметр |
| `gen` | генератор модуля листа отказал | текст называет блок и причину |
| `docs` (предупр.) | нет `docs.md` | напиши описание |
| `sim` (предупр.) | у выхода драйвера нет `sim` | добавь `sim = <значение>` — с ним схема работает в симуляции |
| `description` (предупр.) | пустое `description` в `[block]` | одна фраза о блоке |

## Частые причины `wasm`

| Текст | Причина в Rust | Исправление |
| --- | --- | --- |
| `импорт env.memcpy недоступен` / `env.memset` | код на C собран с libc | C: `-nostdlib`, свои циклы копирования |
| `импорт env.<имя> недоступен` | функция объявлена в `extern "C"` без `#[link(wasm_import_module = "crab")]` (или `"bus"`) | добавь атрибут к блоку `extern` |
| `нет такой функции шины: bus.<имя>` | опечатка или функции нет в списке | имена — по таблице в `wasm-api.md` |
| `у импорта … не та сигнатура` | типы аргументов не те (`f32` вместо `f64`, `u8` вместо `i32`) | `crab.*` — `i32`/`f64` как в таблице, `bus.*` — все `i32` |
| нет экспорта `step` | нет `#[no_mangle] pub extern "C" fn step(dt_ms: i32)` | добавь |
| таблицы / косвенные вызовы | `dyn Trait`, `fn`-указатели, `core::fmt` (`format!`, `write!`) | убери; для журнала — готовые байтовые строки `b"..."` |
