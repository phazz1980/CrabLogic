# Формат `block.toml` (блок для мастера на Rust)

Только то, что работает с `block.wasm`. Поля для шаблонов C++ (`includes`, `libraries`, `static`,
`runtime`) не пиши: мастер на Rust их не использует.

## `[block]`

| Поле | Обязательно | Что это |
| --- | --- | --- |
| `type` | да | имя типа = имя папки блока: строчная латиница, цифры, `_` (`run_hours`). Не занимай имя встроенного блока (`crablogic block check` скажет) |
| `name` | да | название в библиотеке, по-русски («Счётчик моточасов») |
| `group` | да | папка в библиотеке: «Сравнение», «Время», «Датчики», «Математика», «Логика» или своя |
| `description` | да (иначе предупреждение) | одна фраза: что делает блок |
| `symbol` | нет | короткая надпись на блоке: `MH`, `BH1750`; без неё — `name` |
| `memory` | нет | `true`, если блок помнит что-то между циклами (счётчик, таймер, фронт, фильтр). Обратная связь в схеме допустима только через такой блок |
| `single` | нет | `true` — в проекте только один такой блок |

## `[[input]]` и `[[output]]` — порты

| Поле | Обязательно | Что это |
| --- | --- | --- |
| `name` | да | латиница, цифры, `_`; без пробелов и точек; не `id`/`type`; уникально среди всех входов, выходов и параметров |
| `type` | да | `bool`, `int`, `float`. **`string` в `block.wasm` не передаётся** — не используй |
| `label` | нет | подпись по-русски («Работа») |
| `default` | нет, только вход | значение неподключённого входа (`false`, `0`, `0.0`); без него вход обязательно подключать |
| `sim` | нет, только выход | значение выхода в симуляции на ПК для **драйвера** (там шины нет): `sim = 21.5`, `sim = true`. У драйвера ставь всем выходам |
| `when` | нет | условие на параметры: порт есть, только пока оно верно (`count >= 3`, `mode == 1`) |
| `description` | нет | подсказка при наведении; пиши с единицами («Освещённость, лк») |

Неявно приводится только `int` → `float`. Номер порта в `block.wasm` — его место среди `[[input]]`
(или `[[output]]`) по порядку, с нуля. **Не переставляй порты без пересборки `block.wasm`.**

## `[[param]]` — параметры (задаются в свойствах, не проводом)

| Поле | Обязательно | Что это |
| --- | --- | --- |
| `name`, `label`, `description`, `when` | | как у портов |
| `type` | да | `bool`, `int`, `float`, `duration` (время: `"500ms"`, `"2s"`; в `block.wasm` приходит в мс), `pin` (вывод платы) |
| `default` | нет | без него параметр обязателен. Должен быть в границах `min`/`max` и своего вида (`int` — `5`, `float` — `5.0`, `duration` — `"1s"`) |
| `min`, `max` | нет | границы чисел; у `duration` — в мс |
| `show` | нет | что писать под блоком: `named` (по умолчанию), `value`, `hidden` |
| `[[param.choice]]` | нет | выпадающий список: `value = 0`, `label = "Режим 1"`; `default` должен быть в списке |

Только для `type = "pin"`:

| Поле | Что это |
| --- | --- |
| `mode` | `io` (по умолчанию), `in`, `out`, `pwm`, `adc`, `dac` — какие выводы подходят |
| `bus` | общая шина: `i2c-sda`, `i2c-scl`, `spi-sck`, `spi-mosi`, `spi-miso`, `onewire`. Блоки с одинаковым `bus` могут стоять на одном выводе |
| `shared` | `true` — несколько блоков **этого типа** делят вывод |

Для драйвера `int`-параметр с `bus = "i2c-address"` — адрес I²C (**десятичный**: 0x23 = 35), с
`bus = "uart-port"` — номер UART (1 или 2). Мастер даёт драйверу **только** заявленные так выводы,
адрес и порт: к чужим функция шины вернёт −1.

Номер параметра в `block.wasm` — его место среди `[[param]]`, с нуля; параметры с `when`, которые
сейчас выключены, номера не теряют.
