# `block.wasm`: интерфейс, сборка, ограничения

Код блока — модуль WASM на любом языке (образцы — на Rust). Мастер вклеивает его в модуль листа, у
каждого экземпляра блока своя копия памяти и переменных. То же для человека — в справке редактора,
страница «Драйверы железа на WASM».

## Экспорты модуля

| Экспорт | Обязательно | Что это |
| --- | --- | --- |
| `step(dt_ms: i32)` | да | один цикл листа; `dt_ms` — сколько мс прошло с прошлого |
| `init()` | нет | один раз при запуске модуля: сбросить состояние, настроить шину |
| `__heap_base` | да | граница данных модуля (даёт флаг сборки ниже) |

## Импорты из модуля `crab` (логика и драйверы)

| Функция | Что делает |
| --- | --- |
| `input(i: i32) -> f64` | вход номер `i` |
| `param(i: i32) -> f64` | параметр номер `i` (`duration` — в мс, `pin` — номер GPIO) |
| `output(i: i32, v: f64)` | задать выход номер `i` |
| `log(ptr: i32, len: i32)` | строка UTF-8 в журнал мастера (не чаще раза в секунду) |

`bool` передаётся как `0.0`/`1.0` (читай `input(i) != 0.0`), `int` — как целое в `f64`. Строк нет.

## Импорты из модуля `bus` (только драйверы)

Все возвращают `i32`: ≥ 0 — успех или значение; −1 — вывод/адрес не заявлен в `block.toml`; −2 — ошибка
шины или нет ответа; −3 — тайм-аут; −4 — неверные аргументы. Функции обмена при успехе возвращают число
переданных/принятых байт: сравнивай с длиной (`i2c_read(addr, buf, 6) == 6`). Указатели — адреса в памяти
самого модуля: буфер — `static mut BUF: [u8; N]` или локальный массив, адрес — `core::ptr::addr_of_mut!(BUF).cast()`
или `buf.as_ptr()`.

| Функция | Что делает |
| --- | --- |
| `gpio_mode(pin, mode)` | 0 вход, 1 выход, 2 подтяжка вверх, 3 вниз, 4 открытый сток |
| `gpio_read(pin)`, `gpio_write(pin, level)` | уровень вывода |
| `i2c_open(sda, scl, hz)` | открыть I²C (`hz` 0 — 100 кГц); звать в `init` или до первого обмена |
| `i2c_write(addr, ptr, len)`, `i2c_read(addr, ptr, len)` | передать / принять до 256 байт |
| `i2c_write_read(addr, wptr, wlen, rptr, rlen)` | записать номер регистра и прочитать |
| `uart_open(port, tx, rx, baud)`, `uart_write`, `uart_read(port, ptr, cap)`, `uart_available(port)` | UART1/UART2, 8N1 |
| `spi_open(sck, mosi, miso, hz)`, `spi_transfer(cs, ptr, len, mode)` | SPI; принятое кладётся на место отправленного |
| `ow_reset(pin)`, `ow_write`, `ow_read`, `ow_read_bit`, `ow_write_bit` | 1-Wire |
| `pulse_read(pin, start_us, ptr, count)` | стартовый импульс и замер длин уровней аппаратным RMT, до 128 уровней, уровень дольше 300 мкс заканчивает замер (DHT22) |
| `micros()` | микросекунды; `delay_us(us)` — пауза не больше 100 мкс |

**Шаг не должен ждать.** Датчику нужно 180 мс на измерение — запусти в одном шаге, прочитай через
нужное число шагов (копи `dt_ms`). Ошибка шины — выход `ok = false` и повтор позже, не цикл.

## Сборка (Rust)

`Cargo.toml`: `crate-type = ["cdylib"]`, в `[profile.release]` — `opt-level = "s"`, `lto = true`,
`panic = "abort"`; свой `[workspace]`. Код: `#![no_std]`, `#[panic_handler]` с бесконечным циклом,
импорты — `#[link(wasm_import_module = "crab")] extern "C" { ... }`.

```
rustup target add wasm32-unknown-unknown      # один раз; спроси пользователя перед установкой
set RUSTFLAGS=-C target-cpu=mvp -C link-arg=-zstack-size=4096 -C link-arg=--export=__heap_base
cargo build --release --target wasm32-unknown-unknown
```

Готовый `target/wasm32-unknown-unknown/release/<crate>.wasm` копируется в папку блока как `block.wasm`.
В образцах это делает `build.ps1`.

C: `clang --target=wasm32 -O2 -mcpu=mvp -nostdlib -Wl,--no-entry -Wl,-z,stack-size=4096
-Wl,--export=step -Wl,--export=init -Wl,--export=__heap_base`.

## Нельзя

- Импорты не из списков выше (`env.*`, WASI, `memcpy` из libc): ошибка «импорт … недоступен».
- `memory.grow`, таблицы и косвенные вызовы (`dyn Trait`, указатели на функции, замыкания в `Box`),
  пассивные сегменты данных.
- Память больше 32 КБ (стек 4 КБ + данные): никаких больших массивов и `alloc`.
- Строки. Математика `sin`, `pow`, `sqrt` в `no_std` — через крейт `libm` (он без импортов), не через `std`.
- Бесконечные циклы и ожидание в `step`.
