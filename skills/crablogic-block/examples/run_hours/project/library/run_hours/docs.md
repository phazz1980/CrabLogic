# Моточасы

Считает, сколько часов работало оборудование, и сколько раз его запускали. Пока `run` истинен, к наработке
добавляется время цикла; каждый фронт `run` (из false в true) увеличивает счётчик запусков.
Выход `service` включается, когда наработка достигла `limit` часов — пора на обслуживание.
`reset` обнуляет наработку и запуски.

| Порт | Тип | Что это |
| --- | --- | --- |
| `run` (вход) | bool | оборудование работает (по умолчанию false) |
| `reset` (вход) | bool | сброс счётчиков (по умолчанию false) |
| `hours` (выход) | float | наработка, ч |
| `starts` (выход) | int | число запусков |
| `service` (выход) | bool | `hours >= limit` |

Параметр: `limit` — лимит наработки в часах (по умолчанию 1000).

Заметки:
- Значения хранятся в памяти модуля и **не переживают перезагрузку** платы: после включения счёт идёт с нуля.
  Для сохранения во флеш нужен отдельный блок («Сохранение во флеш»).
- Пока `reset` истинен, счёт стоит; если при снятии сброса `run` истинен, это считается новым запуском.
- Блок — пример пользовательского блока на WASM (`src/lib.rs`); работает только с мастером на Rust.

```toml
[[block]]
id = "pump_hours"
type = "run_hours"
limit = 500.0
```
