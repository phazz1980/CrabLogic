# Окно значений

Сравнивает входное значение с окном от `low` до `high` и говорит, где оно: внутри, выше или ниже.
Границы входят в окно: при `value = low` или `value = high` выход `inside` истинен. Блок без памяти:
выходы зависят только от текущих значений.

| Порт | Тип | Что это |
| --- | --- | --- |
| `value` (вход) | float | проверяемое значение (целое приводится к дробному) |
| `inside` (выход) | bool | `low <= value <= high` |
| `above` (выход) | bool | `value > high` |
| `below` (выход) | bool | `value < low` |

Параметры: `low` — нижняя граница (по умолчанию 10), `high` — верхняя (по умолчанию 20).
Если `low > high`, окно пустое: `inside` ложен всегда.

Блок — пример пользовательского блока на WASM (`block.wasm`, исходник `src/lib.rs`); работает только с
мастером на Rust.

```toml
[[block]]
id = "temp_window"
type = "window_check"
low = 18.0
high = 25.0
```
