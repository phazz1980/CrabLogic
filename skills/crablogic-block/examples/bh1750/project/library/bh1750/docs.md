# BH1750

Измеряет освещённость датчиком BH1750 по I²C и выдаёт её в люксах. Драйвер включает датчик, запускает
непрерывное измерение высокого разрешения (команды `0x01`, `0x10`) и раз в `period` читает два байта
(старший первым); люксы = значение / 1,2. Лист при этом не ждёт: измерение идёт в самом датчике.
Если датчик не отвечает, `ok = false`, выход `lux` хранит последнее удачное значение, а драйвер
пробует включить датчик снова через `period`.

| Порт | Тип | Что это |
| --- | --- | --- |
| `lux` (выход) | float | освещённость, лк |
| `ok` (выход) | bool | датчик ответил при последнем чтении |

Параметры:

| Параметр | По умолчанию | Что это |
| --- | --- | --- |
| `address` | 35 (0x23) | адрес I²C: 35 при ADDR на земле, 92 (0x5C) при ADDR на питании |
| `sda` | 21 | вывод SDA |
| `scl` | 22 | вывод SCL |
| `period` | 500 мс | как часто читать (не меньше 200) |

Подключение: VCC — 3,3 В, GND — земля, SDA и SCL — к выводам шины (на ESP32 обычно 21 и 22); подтяжки к
питанию есть на большинстве плат-модулей. Первое чтение — примерно через 180 мс после включения, до него
`lux = 0`. В симуляции на ПК выходы равны 120 лк и `ok = true` (драйвер там не выполняется).

Работает только с мастером на Rust (возможность `bus`). На железе не проверено.

```toml
[[block]]
id = "light"
type = "bh1750"
address = 35
sda = 21
scl = 22
period = 500
```
