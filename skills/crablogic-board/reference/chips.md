# Выводы чипов: что можно, что нельзя

Это те же правила, по которым проверяет программа (`crab-core/src/pins.rs`). Номера — GPIO.

## ESP32

| Выводы | Особенность |
| --- | --- |
| 0–5, 12–19, 21–23, 25–27, 32, 33 | обычные: вход, выход, ШИМ |
| 34, 35, 36, 39 | **только вход**: нет выхода и внутренней подтяжки (`functions = ["din", "adc"]`) |
| 6–11 | **флеш-память модуля — не выводить** |
| 20, 24, 28–31, 37, 38 | у чипа нет — проверка ответит «нет вывода» |
| 1, 3 | UART0: заливка и консоль мастера по USB — не для периферии |
| 0, 2, 5, 12, 15 | strapping: уровень при включении влияет на загрузку; реле и кнопки на них — осторожно, напиши в `note` |
| 32–39 | АЦП1 — работает всегда |
| 0, 2, 4, 12–15, 25–27 | АЦП2 — **не работает при включённом Wi-Fi**; отметь это в `note` |
| 25, 26 | ЦАП (`dac`) — только они |

Шины мастера по умолчанию: I²C — SDA 21, SCL 22; UART1 — RX 26, TX 27; UART2 — RX 16, TX 17.
Ethernet LAN8720 занимает выводы RMII (0, 19, 21, 22, 25, 26, 27 и MDC/MDIO) — если он распаян, впиши
их с `busy`.

## ESP32-C3

| Выводы | Особенность |
| --- | --- |
| 0–10 | обычные: вход, выход, ШИМ |
| 0–4 | АЦП1; 5 — АЦП2 (не работает с Wi-Fi) |
| 11–17 | **флеш-память — не выводить** |
| 18, 19 | встроенный USB: заливка и связь с компьютером |
| 20, 21 | UART0 |
| 2, 8, 9 | strapping: 9 — обычно кнопка BOOT, 8 — светодиод на многих платах |

Связь с компьютером у C3 идёт **либо** через встроенный USB (18/19 — так у большинства мини-плат), **либо**
через микросхему USB-UART на UART0 (20/21 — у «Dev Module» с CH340/CP2102). Какая пара занята, зависит
от платы: спроси пользователя. Другую пару можно отдать под периферию — с `busy`, где названа причина чипа.

ЦАП у C3 нет. Шины мастера по умолчанию: I²C — SDA 8, SCL 9; UART1 — RX 18, TX 19. Последнее совпадает
с USB: если плата связана с компьютером через встроенный USB, выводы UART1 в проектах задаются свои.
