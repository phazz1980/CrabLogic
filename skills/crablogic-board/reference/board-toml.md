# Формат `board.toml`

Все поля. Строки — в двойных кавычках, числа без кавычек. Комментарии `#` можно и нужно оставлять:
откуда сведения, что не проверено.

## `[board]` — сама плата

| Поле | Обязательно | Что это |
| --- | --- | --- |
| `id` | да | строчные латинские буквы, цифры, `_`; совпадает с именем папки |
| `name` | да | как плата видна в списках («Kincony KC868-A6») |
| `chip` | да | `esp32` или `esp32c3` (от чипа зависят UART, АЦП и запрещённые выводы) |
| `fqbn` | да | `esp32:esp32:esp32` для ESP32, `esp32:esp32:esp32c3` для ESP32-C3; по нему выбирается образ мастера |
| `version` | нет | целое; увеличивай, когда меняешь выводы или периферию |

`[board.options]` не пиши: это настройки сборки скетча Arduino, мастер на Rust их не использует.

## `[[pin]]` — вывод, выведенный наружу

Повторяется для каждого вывода. Если ни одного `[[pin]]` нет, в проектах доступны все выводы чипа.

| Поле | Обязательно | Что это |
| --- | --- | --- |
| `gpio` | да | номер GPIO чипа (не номер ножки модуля и не подпись) |
| `name` | да | как напечатано на плате: `A1`, `IO-2`, `RS485 RX`; в списках будет «A1 · GPIO36» |
| `note` | нет | пояснение для окна платы |
| `busy` | нет | чем вывод занят на плате; блок, поставленный на него, получит предупреждение с этим текстом |
| `functions` | нет | что вывод умеет на плате: `din` цифровой вход, `dout` выход, `pwm` ШИМ, `adc` АЦП, `dac` ЦАП. Без поля — всё, что умеет чип. Шире чипа нельзя (см. `chips.md`) |

Блок видит вывод, только если функция подходит: «Цифровой вход» — `din`, «Цифровой выход» — `dout`,
«ШИМ-выход» — `pwm`, «Аналоговый вход» — `adc`. Выводы шин (I²C расширителей, RS-485) тоже описывай —
с `busy`, чтобы пользователь не поставил на них свой блок.

## `[[device]]` — распаянная периферия

Готовый блок, копия встроенного, с закреплёнными адресом и шиной. Тип блока в проектах —
`<id платы>_<id устройства>`, в библиотеке — «Название платы: Название устройства», один на проект.

| Поле | Обязательно | Что это |
| --- | --- | --- |
| `id` | да | латиница, уникален на плате: `relays`, `inputs` |
| `kind` | да | `pcf8574_out` (реле, выходы) или `pcf8574_in` (входы) |
| `name` | да | «Реле», «Входы» |
| `description` | нет | что за устройство, адрес, шина; «не проверено на железе», если так |
| `channels` | да | подписи каналов по порядку P0, P1…: `["K1", "K2", …]`; портов блока столько же (до 8) |
| `address` | да | адрес I²C **десятичным** числом: 0x20 = 32, 0x22 = 34, 0x24 = 36, 0x27 = 39, 0x38 = 56 |
| `sda`, `scl` | да | GPIO шины I²C; `-1` — выводы по умолчанию (ESP32: 21/22, ESP32-C3: 8/9) |
| `inverted` | нет | `true`, если реле включаются нулём или активный вход читается нулём (так у Kincony) |
| `period` | нет | только `pcf8574_in`: период опроса, по умолчанию `"20ms"` |

Все расширители одной платы сидят на одной шине I²C мастера: `sda`/`scl` у них одинаковые.

## `[[expander_pin]]` — отдельные выводы расширителя (необязательно)

Если описать, выводы расширителя появятся в списке выводов блоков «Цифровой вход» и «Цифровой выход»
под заголовком «Плата: <имя устройства>» («P0 · K1»). Без этой таблицы расширитель доступен блоком
из `[[device]]` целиком.

| Поле | Обязательно | Что это |
| --- | --- | --- |
| `device` | да | `id` из `[[device]]` |
| `pin` | да | вывод микросхемы 0–7 (P0…P7) |
| `name` | да | подпись на плате: `K1` |
| `note` | нет | пояснение |
| `functions` | нет | `["din"]`, `["dout"]` или оба (по умолчанию) |

## Где лежит плата

- Своя библиотека пользователя: `user_library/boards/<id>/` рядом с программой (в дистрибутиве —
  `CrabLogic/user_library/boards/`). Отсюда плата видна во всех проектах.
- Проект `.crab` хранит копию своей платы внутри; проект-папка (как примеры) — в `user_boards/<id>/`.
  На другом компьютере такая плата устанавливается сама при открытии проекта.
- Обмен одним файлом — `.crabboard` («Библиотека → Экспорт платы» / «Импорт платы из файла…»).
