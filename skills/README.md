# Инструкции для ИИ-помощников (skills)

Папка для любой ИИ-модели (Claude Code, Codex, Cursor и др.), которая делает что-то для CrabLogic по
просьбе пользователя, не читая код программы. Каждая подпапка — одна задача: точка входа `SKILL.md`
(когда её применять и порядок работы), справочники `reference/`, образцы `examples/`, чек-лист.

| Папка | Когда применять |
| --- | --- |
| [`crablogic-board/`](crablogic-board/SKILL.md) | добавить свою плату (контроллер): выводы, распаянные реле и входы, описание |
| [`crablogic-block/`](crablogic-block/SKILL.md) | сделать свой блок: логика или драйвер датчика, код `block.wasm` на Rust |

Хуки и проверка блока — `crablogic-block/hooks/check.ps1`; `dist/` — файлы для корня папки программы
(`AGENTS.md`, `CLAUDE.md`, `.claude/settings.json` с хуками, `.cursor/rules/`), их кладёт `scripts/copy-skills.ps1`
(его вызывает `build-dist.ps1`).

Общие правила:
- Программа с версии 2.0 работает только с мастер-прошивкой на Rust: платы — ESP32 и ESP32-C3, код на
  C++ (`esp32.cpp.tmpl`, `native.cpp`, библиотеки Arduino) не используется.
- Результат проверяется командами `crablogic` (лежит рядом с программой, в репозитории —
  `cargo run -p crab-cli --`), а не на глаз.
- Код программы (`crates/`) не правится: всё делается файлами в пользовательской библиотеке.
