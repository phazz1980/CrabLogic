# ИИ-помощник и MCP

Помощник читает схему, добавляет и соединяет блоки, проверяет результат, собирает и заливает прошивку, читает живые значения и создаёт новые блоки. Набор команд один и тот же для чата в редакторе и для MCP-сервера.

## Чат в редакторе

Вкладка «ИИ» справа. Опишите задачу словами, например «включай насос, когда давление ниже 2 бар дольше 5 секунд». Каждую правку помощника можно отменить Ctrl+Z.

Для работы нужен ключ Claude в переменной окружения `ANTHROPIC_API_KEY`. Для другого сервиса с OpenAI-совместимым API задайте `CRAB_AI_BASE_URL`, `CRAB_AI_KEY` и `CRAB_AI_MODEL`. Переменные нужно задать до запуска редактора.

Читать живые значения помощник может, только когда запущена отладка ([отладка](help:debug)).

## MCP-сервер

Программа `crab-mcp` предоставляет те же команды любому MCP-клиенту (Claude Desktop, Claude Code и другим) через стандартный ввод-вывод. Команды:

- `open_project`, `get_schema`, `list_block_types`, `get_block_type`;
- `add_block`, `add_variable_block`, `move_block`, `rename_block`, `remove_block`;
- `connect`, `disconnect`, `set_input_const`, `set_params`, `set_param_input` (параметр как вход), `invert_port`;
- `set_variable`, `remove_variable`, `bind`;
- `check`, `generate`, `build`, `upload`, `read_live_values`, `create_block_type` (шаблон кода `template` и/или нативная часть `native` — C++ для датчика, шины или библиотеки Arduino; файл проверяется до записи, `get_block_type` показывает его).

Начните с `open_project`, `get_schema` и `list_block_types`; после правок смотрите поле `check` в ответе. Правки сразу сохраняются в файл проекта `.crab`. Папку библиотеки можно задать переменной `CRAB_LIBRARY`.

> Подключение конкретных клиентов здесь не описано: оно зависит от клиента. Сборка и заливка через ИИ на реальном железе не проверялись.

## Свой блок или плата с ИИ в папке программы

В папке программы лежат инструкции для ИИ-помощников, которые работают с файлами (Claude Code, Cursor, Codex):
`skills/crablogic-block/` — свой блок (логика или драйвер датчика, код `block.wasm` на Rust),
`skills/crablogic-board/` — своя плата. Откройте папку программы в таком помощнике и попросите: «сделай блок…»,
«добавь мою плату…». Он найдёт инструкцию по `AGENTS.md` (Claude Code — по `CLAUDE.md`, Cursor — по
`.cursor/rules/`), исходники блоков держит в `blocks_src/`, готовый блок кладёт в `user_library/`.

В Claude Code проверка идёт сама (`.claude/settings.json`): после правки `block.toml`, `docs.md` или
тестового проекта запускается `crablogic block check` или `crablogic check`, и ошибки возвращаются помощнику;
перед завершением работы проверяются все блоки, изменённые за последние 6 часов. Другим помощникам то же
делает команда `skills/crablogic-block/hooks/check.ps1 <папка блока>`. Для сборки `block.wasm` нужен Rust с
целью `wasm32-unknown-unknown`.

## Советы

- Просите проверку после правок: «проверь схему».
- Если нужного блока нет, помощник может создать пользовательский — см. [библиотеку блоков](help:library).
