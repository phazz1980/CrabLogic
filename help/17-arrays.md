# Массивы

Массив — набор однотипных значений фиксированной длины: показания восьми датчиков, скользящее окно, таблица уставок, очередь команд. Массив лежит в памяти модуля листа, блоки обращаются к нему по имени. По проводам идут только обычные значения: индекс, значение, флаг.

**Что есть сейчас (запись от 20.11.2026).** Массивы создаются в левой панели, в папке «Массивы», блоки работы с ними лежат в библиотеке справа (см. ниже); массивы описываются в `logic.toml` проекта. Блоки структур ещё не сделаны. **Не проверено на железе:** блоки проверены в симуляции и в тестовом исполнителе модулей на компьютере, на плате не запускались; окна редактора (создание массива, перетаскивание) проверены только сборкой, не глазами.

## В редакторе

**Слева** в дереве проекта папка «Массивы» с кнопкой «+», как у переменных: здесь массивы только создаются, меняются и удаляются. «+» открывает окно массива: имя, тип элемента, длина, описание и таблица начальных значений (пустое поле — ноль). Двойной щелчок по строке или пункт «Изменить...» открывает то же окно, «Удалить вместе с блоками» убирает массив и все его блоки. Строка окрашена по типу элементов, оранжевый «[✕]» после имени значит, что ни один блок не использует массив.

**Справа** в библиотеке блоков группа «Массивы»: чтение, запись, заполнить, копировать, сумма, минимум, максимум, поиск, сдвиг, кольцевой буфер, стек. Блок ставится на лист перетаскиванием или двойным щелчком, как любой другой. Если в проекте ровно один массив, подходящий блоку, блок берёт его сам; иначе выберите массив в свойствах блока (двойной щелчок по блоку): параметр `array` — список массивов проекта. У блока «Копировать» ещё параметр `dest`, он предлагает только другие массивы того же типа. При переименовании массива блоки следуют за новым именем. Пока массив не выбран, проверка схемы сообщает об этом ошибкой.

## Отладка

В онлайн-отладке (плата с мастер-прошивкой, модули залиты с «отладкой») модуль сообщает элементы массивов так же, как выходы блоков: в окне «Входы и переменные» появляется раздел «Массивы», по одной сворачиваемой группе на массив, в группе строка на каждый элемент (`имя[номер]`) с текущим значением. Правая кнопка по строке: «Форсировать» (значение записывается в сам элемент массива и остаётся там после снятия форсировки), «Добавить на график». В командной строке `crablogic monitor` печатает те же значения.

- Показываются массивы, которые использует хотя бы один блок, и **первые 64 элемента** каждого (на модуль приходится не больше 128 отслеживаемых значений вместе с выходами блоков; не поместившиеся элементы не показываются).
- Массивы строк в отладке не показываются (их пока нет и в модулях).
- Запись «один раз» (как у переменной) для элементов не предусмотрена: используйте форсировку или блок «Запись».

## Описание массива

```toml
[[array]]
name = "window"        # имя: общее с переменными, не должно повторяться
type = "float"         # bool, int, float, byte или string (string пока только в симуляции)
len = 8                # длина: до 256 на ESP32 и ESP32-S3, до 64 на ESP32-C3
items = [1.5, 2.0]     # начальные значения по порядку; остальные элементы нули
description = "Последние 8 замеров"
```

- `byte` — целое 0…255 (в памяти один байт, при записи берутся младшие 8 бит). `int` — 32 бита с переполнением по кругу. `bool` — 0 или 1. `float` — 32-битное число.
- Начальная таблица записывается при каждом запуске модуля. Сохранения во флеш (`retain`) у массивов пока нет.
- Все блоки одного массива должны стоять на **одном листе**: общие массивы между листами пока не поддержаны, сборка скажет об этом ошибкой.
- Не помещается в память (64 КБ на модуль вместе со строками) — ошибка сборки.
- Память массивов входит в оценку ОЗУ платы («ОЗУ платы: ≈ X из Y КБ» в редакторе): каждый массив считается один раз на модуль, где его используют. Если блоки вместе с массивами не помещаются в ОЗУ платы, проверка схемы выдаёт предупреждение.

## Блоки

Блок указывает массив параметром `array`. Тип портов `value` и `out` берётся из типа элемента массива (у `byte` это целое). Индексы считаются с нуля.

| Блок (`type`) | Входы | Выходы | Что делает |
|---|---|---|---|
| Чтение (`array_get`) | `index` | `out`, `err` | Читает элемент |
| Запись (`array_set`) | `index`, `value` | `err` | Пишет элемент |
| Заполнить (`array_fill`) | `value`, `go` | | Пока `go` включён, пишет `value` во все элементы |
| Копировать (`array_copy`, параметр `dest`) | `go` | `err` | По фронту `go` копирует массив в `dest` (по меньшей длине) |
| Сумма (`array_sum`) | | `out` | Сумма всех элементов (int, float, byte) |
| Минимум, максимум (`array_min`, `array_max`) | | `out`, `index` | Значение и индекс первого такого элемента (int, float, byte) |
| Поиск (`array_find`) | `value` | `index`, `found` | Индекс первого равного элемента, −1 если нет |
| Сдвиг (`array_shift`) | `value`, `go` | | По фронту `go` элементы сдвигаются на место вверх, `value` встаёт на место 0 |
| Кольцевой буфер (`array_ring`) | `value`, `push` | `head`, `count` | По фронту `push` пишет в голову; полный буфер затирает самый старый элемент |
| Стек (`array_stack`) | `value`, `push`, `pop` | `out`, `count`, `empty`, `full`, `err` | `push` кладёт, `pop` снимает; полный стек не принимает новое значение |

Правила, общие для всех блоков:

- **Индекс вне массива** не ломает плату: чтение даёт 0, запись пропускается, выход `err` включается на этом скане. Каждое такое обращение (чтение или запись) считается в счётчике отказов модуля: мастер складывает его с отказами платы (`list`, окно «Диагностика»). Нужен мастер с поддержкой счётчика (перезалейте мастер); старый мастер работает, но отказ не считает.
- Входы `go`, `push`, `pop` срабатывают **по фронту** (ложь → истина); удержанный сигнал действует один раз.
- Сумма, минимум и максимум на массиве `bool` или `string` — ошибка проверки.
- Если один массив записывают несколько блоков (запись, заполнение, сдвиг, кольцо, стек, приёмник копирования), второй получает предупреждение: записи идут в порядке выполнения блоков.
- Копирование в массив другого типа, в самого себя или в несуществующий — ошибка проверки. Константный индекс вне длины тоже ошибка.

## Структуры

Структура — группа именованных полей разных типов: рецепт «температура, время, вентилятор», набор уставок одного узла. Поля бывают `bool`, `int`, `float`, `byte` (строки в структурах пока не поддерживаются). Структура лежит в проекте, как массив, и блоки обращаются к ней по имени.

Структуры создаются в левой панели, в папке «Структуры» (кнопка «+», окно с таблицей полей: имя, тип, начальное значение); блоки «Структура: собрать» и «Структура: разобрать» лежат в библиотеке справа, в группе «Массивы». Перетаскивание строки структуры на лист добавляет блок «разобрать», блок «собрать» добавляется из меню строки. В файле проекта структура — `[[struct]]` с именем и `[[struct.field]]` (имя, тип, необязательное начальное значение `init`). Изменили поля или имя структуры — блоки следуют за ней, провода к исчезнувшим полям снимаются.

- **Собрать** (`struct_pack`, параметр `struct`): по одному входу на каждое поле и вход `go`. Пока `go` включён (по умолчанию включён), поля записываются из входов; поле без провода получает своё начальное значение (или 0). Поле хранится так же, как значение этого типа на плате: `byte` — младшие 8 бит, `int` — 32 бита с переходом через границу, `bool` — 0 или 1.
- **Разобрать** (`struct_unpack`): по одному выходу на каждое поле. Читает значение прошлого скана, поэтому в схеме можно делать обратную связь через структуру, как через переменную.
- Порты блока зависят от полей: изменили поля структуры — порты блока обновились, провода к исчезнувшим полям снимаются.
- Проверка: нет структуры или она не выбрана, в структуре строка или поле с именем `go`, структуру собирают два блока (предупреждение: порядок записей — порядок выполнения).
- Структура на одном листе: блоки собрать и разобрать должны стоять на листах одного модуля.

## Примеры

- `examples/array_average` — скользящее среднее давления по окну из 8 замеров (кольцевой буфер и сумма): насос включается по среднему, а лампа показывает «давление скачет» по размаху (максимум минус минимум).
- `examples/struct_recipe` — структура «рецепт» (температура, время, вентилятор): кнопка «записать» кладёт значения в поля блоком «собрать», блок «разобрать» отдаёт их обратно, светодиод повторяет поле `fan`.
- `examples/array_tools` — таблица уставок с начальными значениями, чтение и запись, журнал на сдвиге, снимок журнала копированием, стек, поиск и заполнение флагов.

Ошибки описания и блоков массивов — в разделе «Проверка схемы», вид `array`.
