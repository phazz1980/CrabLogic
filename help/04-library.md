# Библиотека блоков

Каждый блок — папка `library/<тип>/` с тремя файлами: `block.toml` (название, группа, входы, выходы, параметры), `esp32.cpp.tmpl` (шаблон кода Arduino C++; у встроенных блоков (логика, таймеры, математика, биты и слова, текст, ПИД, таблица масштаба, выводы, датчики, расширители PCF8574, UART, Modbus, сеть, веб-интерфейс) вместо него код на Rust внутри программы, редактор блока показывает его C++) и `docs.md` (описание и пример). Новый блок появляется без перекомпиляции программы. Блоку с датчиком, шиной или библиотекой Arduino можно добавить четвёртый файл `native.cpp` — код C++, который встраивается в мастер-прошивку (см. «Редактор блока», раздел «Код C++ для платы»).

## Встроенные и пользовательские

Встроенные блоки идут с программой и открываются только для просмотра. Пользовательские лежат в папке `user_library/` рядом с `library/`. Пользовательский блок не может занять тип встроенного: такой блок пропускается с предупреждением. В библиотеке справа две вкладки: «Встроенные» и «Пользовательские».

## Блоки проекта

Пользовательские блоки, которые стоят на схеме, сохраняются внутри файла проекта `.crab`. Если такого блока
нет в библиотеке программы (проект пришёл с другого компьютера, открыт пример со своими блоками), он **не**
добавляется в библиотеку сам: блок появляется на вкладке «Блоки проекта» в левой панели. Там же его можно
перетащить на лист, двойным щелчком поставить на схему, а правой кнопкой открыть «Изменить блок...». Правки
такого блока остаются в проекте и записываются в файл при сохранении.

Блоки проекта работают, пока проект открыт. При закрытии проекта (открыт другой проект или закрыта программа)
они уходят из программы; в файле проекта они остаются и вернутся при следующем открытии. Чтобы ставить блок и в
другие проекты, нажмите «В библиотеку»: блок копируется в `user_library/` в свой раздел и дальше живёт как
обычный пользовательский блок. Если в библиотеке уже есть папка с таким именем, блок не копируется — об этом
скажет сообщение внизу.

Если блок с тем же типом в проекте и в библиотеке отличается содержимым, при открытии проекта появится окно
«Блоки проекта и программы» с выбором, какую копию оставить. Командная строка (`crablogic check`, `gen`,
`build`, `gen-wasm`) и MCP-сервер тоже берут блоки проекта только на время работы и библиотеку не меняют.

## Свой блок

«Библиотека → Новый блок...» открывает редактор блока. В нём видно, как блок выглядит на плате, и есть вкладка «Пробная генерация». Правая кнопка на блоке даёт «Посмотреть / Изменить блок...», «Новый блок на основе этого...» и для своих блоков «Удалить блок...». Подробно о вкладках, условиях `when` и шаблоне кода — в разделе [Редактор блока](help:blockeditor); в самом редакторе для этого есть кнопка «? Справка». Блок можно создать и словами через [ИИ-помощника](help:ai).

Если вы поменяли файлы блока вручную, выберите «Библиотека → Перечитать блоки»: справочник блоков в справке обновится тоже.

## Обмен блоками

Каждый свой блок лежит в наборе (по умолчанию «Мои блоки»). Набор хранит одну версию на все блоки, автора и контакты; правка любого блока поднимает версию набора. Набор переносится одним файлом `.crabblocks`: в него попадают блоки, подключаемые библиотеки Arduino и примеры. Создание, импорт и экспорт наборов есть в окне библиотеки, а в командной строке работают `crablogic block list`, `crablogic block export` и `crablogic block import`.

## Справка по блокам

Описание блока берётся из его `docs.md`. Если файла нет, справка покажет порты и параметры из `block.toml`. Весь список с группами — в [справочнике блоков](help:blocks). Размер шрифта в окне справки меняют кнопки «A−», «A+» и «100%» справа от строки поиска. Кнопка «На весь экран» там же разворачивает окно справки на всё рабочее поле, «Свернуть окно» возвращает прежний размер.

Формат `block.toml` подробно описан в файле `library/README.md` в репозитории.
