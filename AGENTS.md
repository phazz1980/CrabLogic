# Для ИИ-агентов

Если пользователь просит сделать что-то в CrabLogic (свою плату, свой блок), сначала открой
[`skills/README.md`](skills/README.md) и работай по инструкции нужной папки:

- своя плата (контроллер) — [`skills/crablogic-board/SKILL.md`](skills/crablogic-board/SKILL.md);
- свой блок (логика или драйвер датчика) — [`skills/crablogic-block/SKILL.md`](skills/crablogic-block/SKILL.md).

Разработка самой программы — по [`CLAUDE.md`](CLAUDE.md).
