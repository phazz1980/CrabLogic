# Modbus: slave у master

Ведомое устройство, которое опрашивает блок «Modbus RTU Master» или «Modbus TCP Master».
Блок не ставится на лист: он создаётся в левой панели под master, там же его настраивают.

`master` — идентификатор блока master; `unit` — адрес устройства (Unit ID, 1..247).
Для Modbus TCP можно задать свой IP-адрес (`ip`) и порт (`port`) у каждого slave в левой панели:
пустой `ip` или `port` 0 — адрес и порт master. Для RTU эти параметры не нужны.
Теги устройства — блоки «Modbus: тег» с параметром `device`, равным идентификатору этого блока.
Число устройств у master ограничено его параметром «Макс. slave».
