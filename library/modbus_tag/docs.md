# Modbus: тег

Один регистр, два регистра (float) или один бит таблицы устройства Modbus.
`device` — идентификатор устройства: блок «Modbus: slave у master» (для master)
или блок Modbus RTU/TCP Slave этой платы (для slave). `table` — holding, input, coil или discrete;
`reg` — адрес в таблице; `kind` — int, float или bool, от него зависят порты.

Направление задаёт связь. Подключён выход (`out`, `out_f`, `out_b`) — значение читается из устройства
(для slave-блока — отдаётся в схему). Подключён вход (`in`, `in_f`, `in_b`) — значение пишется в устройство
(для slave-блока — берётся из схемы). Выход `ok` показывает, отвечает ли устройство.
Подключить оба или ни один из портов значения — ошибка проверки.

`swap` (только для float) меняет местами два 16-битных слова: нужно, если устройство отдаёт младшее слово первым.
