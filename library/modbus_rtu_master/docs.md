# Modbus RTU Master

Ведущее устройство Modbus RTU на UART, обычно через преобразователь RS-485.
Опрашивает ведомые устройства с периодом `period`. Устройства и их теги добавляются
в левой панели под master: устройство — «Modbus: slave у master» (адрес Unit ID),
тег — «Modbus: тег» (таблица, адрес, тип значения). Число устройств ограничено
параметром «Макс. slave» (`slaves`, по умолчанию 4, до 32): чем больше, тем больше ОЗУ на плате.

Адрес и порт slave здесь не используются: у RTU адрес задаёт только Unit ID.

Параметр `uart` — только номер порта (1 или 2). Скорость, чётность (из формата:
8N1, 8E1, 8O1) и выводы RX, TX и DE/RE задаются в настройках платы, раздел
«UART». Порт занят мастером целиком: другие блоки его не используют.

Значение тега, подключённое к выходу, читается с устройства; подключённое ко входу — пишется
на ближайшем опросе. Направление задаёт связь, см. «Modbus: тег».

Пример: `examples/modbus_rtu`.

В модуле WASM протокол ведёт мастер-прошивка (в неё включается Modbus, около +14% flash на ESP32-C3); на плате не проверено.
