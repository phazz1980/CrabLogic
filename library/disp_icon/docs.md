# Значок на экране

Значок из встроенного набора на экране дисплея. Входов нет.

- `display`, `screen`, `x`, `y`, `w`, `h` — как у «Текст на экране».
- `icon` — значок, выбирается из списка: термометр (`thermometer`), капля (`drop`), вентилятор (`fan`), лампа (`lamp`),
  тревога (`alarm`), Wi-Fi (`wifi`), галочка (`check`), крестик (`cross`).
- `font` — размер на OLED: 8 или 16 пикселей (по умолчанию 16); на LCD значок занимает одно знакоместо.
