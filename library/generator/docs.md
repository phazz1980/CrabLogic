# Генератор

Пока вход `en` true (или не подключён), выход `out` попеременно включается
на `time_on` и выключается на `time_off`. Каждый раз, когда `en` включается,
период начинается заново с включённого состояния.

Если `time_on` или `time_off` меняется на лету (параметр-вход), новая длительность
действует с ближайшего переключения. Если цикл дольше фазы и несколько фаз прошло за один
шаг, выход соответствует фазе, в которой оказалось бы время (деление при этом считается
только в таком редком шаге).

```toml
[[block]]
id = "blink"
type = "generator"
time_on = "200ms"
time_off = "800ms"
```
