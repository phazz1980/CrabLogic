# Аналоговый вход

Каждый цикл читает АЦП на выводе `pin` и выдаёт сырой отсчёт 0…4095.
Чтобы получить физическую величину (бары, градусы), подключите после него
блок масштабирования.

На ESP32 при включённом Wi-Fi работает только АЦП1 — выводы 32…39.

С мастером на Rust входы АЦП1 (ESP32 — выводы 32…39, ESP32-C3 — 0…4) оцифровываются в фоне, около 20 000
отсчётов в секунду на все входы: чтение не задерживает цикл, а выход — среднее отсчётов с прошлого цикла, то есть
немного сглажен. Входы АЦП2 читаются по одному отсчёту за цикл, как раньше.

```toml
[[block]]
id = "pressure"
type = "analog_in"
pin = 34
```
