# Строка на экране

Строка из схемы на экране дисплея. Вход `in` — строка (тип `string`); виджет — такой же тег, как «Значение на экране»: его перетаскивают на лист и соединяют со схемой. Пока вход не соединён, показывается пустая строка.

- `display`, `screen`, `x`, `y`, `w`, `h`, `font` — как у «Текст на экране».
- Строка обрезается по ширине виджета `w` (OLED: пиксели, LCD: знакоместа). Ширина 0 — до края экрана.
- Русские буквы на LCD занимают символы знакогенератора: не больше 8 разных на экран (вместе со статичными надписями).
- Показывается не больше 64 байт строки.
