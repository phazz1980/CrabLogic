# DS18B20

Читает температуру с датчика DS18B20. Датчик подключается к выводу `pin`,
между линией данных и питанием 3,3 В нужен резистор 4,7 кОм.

Опрос не останавливает программу: блок запрашивает измерение и забирает
результат через `period`. До первого измерения `temp = 0`, `ok = false`.
Если датчик отвалился, `ok` становится false, а `temp` хранит последнее
удачное значение.

На одной шине может быть несколько датчиков — тогда на каждый свой блок
с тем же `pin` и разным `index`.

На Rust-мастере блок — драйвер `block.wasm` (исходник `drivers/ds18b20`) поверх функций 1-Wire мастера: шаг запускает преобразование и через 750 мс читает результат, не задерживая лист; датчик номер `index` находится поиском адресов один раз (и снова — после ошибки). В симуляции на ПК выходы равны 21,5 °C и `ok = true`.

Нужны библиотеки OneWire и DallasTemperature — `crablogic build` и мастер-прошивка ставят их сами. Пример: `examples/sensors`.

```toml
[[block]]
id = "water"
type = "ds18b20"
pin = 4
```
