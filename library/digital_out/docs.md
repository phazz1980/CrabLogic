# Цифровой выход

Каждый цикл программы выставляет на выводе `pin` уровень по входу `in`.
Для модулей реле, которые включаются низким уровнем, поставьте `inverted = true`.

```toml
[[block]]
id = "pump"
type = "digital_out"
pin = 26
```

Параметр «при аварии» (`on_fault`) работает, когда схема залита модулем на мастер-прошивку: если модуль
упал или его выгрузили, мастер ставит выход в 0 (`0`, по умолчанию), в 1 (`1`) или оставляет как есть (`2`,
«держать»). Уровень логический: при `inverted = true` «выключить» — это высокий уровень на выводе.
Подробнее — [выходы при аварии модуля](help:build).
