# Перезапуск платы (RST)

По переходу входа `go` из false в true плата перезапускается через `delay` (по умолчанию 1 с).
Перед перезапуском выходы всех модулей переходят в безопасное состояние, как при остановке модуля.

- **Защита от петли.** Первые `guard` секунд работы схемы (по умолчанию 30) блок игнорирует `go`,
  выход `blocked` равен true. Удержанная команда или сохранённое сообщение MQTT не заставят плату
  перезагружаться бесконечно.
- **Отмена.** Пока перезапуск ждёт своего времени (`pending`), вход `cancel` = true отменяет его.
- **Причина.** Выход `reason` — текст: `poweron` (питание), `software` (этот блок), `pin`, `panic`,
  `int_wdt`, `task_wdt`, `wdt`, `brownout`, `other`. Его можно отправить в MQTT.
- Блок один на проект. Нужен мастер версии с возможностью `restart`; при заливке модуля редактор скажет, если мастер старый.
- В симуляции перезапуск только отмечается в окне, плата не затрагивается.

Пример: нет связи с MQTT 10 минут — перезапуск (`timer_on` на инверсии `connected` → `go`).

```toml
[[block]]
id = "rst"
type = "restart"
delay = "2s"
guard = "60s"
```
