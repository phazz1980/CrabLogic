# Текстовый LCD

Символьный дисплей 1602 (16×2) или 2004 (20×4) с переходником PCF8574 на шине I²C. Экраны рисуются в конструкторе в сетке знакомест.

- `model` — `1602` или `2004`; виджет, не влезающий в сетку знакомест, проверка схемы отмечает ошибкой.
- `address` — адрес переходника: 0x27 (по умолчанию) или 0x3F у большинства модулей; доступны 0x20–0x27 и 0x38–0x3F. Два дисплея с одним адресом на одной шине — ошибка.
- `sda`, `scl` — выводы шины; `-1` — выводы I²C по умолчанию для платы.
- Вход `screen` — номер показываемого экрана (1, 2, …); вход `backlight` — подсветка.
- Выход `ok` — `true`, если переходник отвечает.

Кириллица: у большинства модулей знакогенератор без русских букв, поэтому недостающие буквы рисуются своими символами. Таких символов в знакогенераторе 8, значит на одном экране можно показать не больше 8 разных русских букв; если их больше, проверка схемы выдаёт предупреждение, а лишние буквы не показываются.

Блок пока описан для схемы и проверки; прошивка дисплея (модуль `block.wasm`) появится на следующих шагах.
