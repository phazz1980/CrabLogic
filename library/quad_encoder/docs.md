# Энкодер

Квадратурный энкодер с каналами A и B: позиция со знаком и направление. Подходит для ручек и
положения вала. Счёт ведёт сама плата, поэтому быстрое вращение не теряет шаги.

**Вход.** `reset` — пока true, позиция равна 0.

**Выходы.**
- `pos` — позиция в шагах (32 бита со знаком, при переполнении заворачивается).
- `dir` — направление последнего шага: 1 вперёд, −1 назад; 0 — стоит (нет шагов 200 мс) или идёт
  сброс.
- `ok` — true, если счётчик открыт. Если нет, `ok = false`, блок раз в секунду пробует снова.

**Параметры.**
- `pin_a`, `pin_b` — выводы каналов (класс «вход»). Если позиция растёт не в ту сторону, поменяйте
  выводы местами.
- `mode` — шагов на период сигнала: x1 — один, x2 — два, x4 — четыре (все перепады A и B). У
  ручки с фиксацией один щелчок обычно равен 4 шагам в x4 или одному в x1.
- `filter` — фильтр, мкс (0 — без фильтра; по умолчанию 1).

**Пределы.**
- ESP32: аппаратный счётчик PCNT, до 40 кГц, не больше 8 счётчиков на плату. Аппаратный фильтр —
  не больше 12 мкс.
- ESP32-C3: счёт в прерываниях GPIO, без потерь до 50 кГц (замер без Wi-Fi: до 100 кГц); частые импульсы нагружают единственное ядро.
- Механические ручки дают дребезг, который короткий фильтр не гасит: ставьте RC-цепочку на каждом
  канале.
- После перезагрузки платы позиция равна 0; чтобы сохранить её, подключите `pos` к блоку
  «Сохранение во флеш».

Пример: `examples/encoder_knob`.

```toml
[[block]]
id = "knob"
type = "quad_encoder"
pin_a = 32
pin_b = 33
mode = 2
```
