# Modbus TCP Slave

Отдаёт по Modbus TCP четыре таблицы с адреса 0: регистры хранения (4x),
входные регистры (3x), катушки (0x) и дискретные входы (1x).

Размеры таблиц в блоке не задаются: они считаются по тегам проекта — блокам «Modbus: тег»,
у которых `device` равен идентификатору этого блока. Размер таблицы —
самый дальний адрес её тегов плюс их размер (int — 1 регистр, float — 2 регистра подряд;
катушки и дискретные входы — по одному биту). Дыры между адресами допустимы и занимают место в таблице.

Направление каждого тега задаёт связь: вход тега подключён — значение берётся из схемы
(«из схемы»); выход подключён — значение отдаётся в схему («в схему»).

Работает через блок «Wi-Fi клиент» (`net = "wifi"`) или «Ethernet» (`net = "ethernet"`) —
нужный блок обязателен.

Один регистр — целое 16 бит; `float` занимает два регистра подряд.

Пример: `examples/modbus_wifi`.
