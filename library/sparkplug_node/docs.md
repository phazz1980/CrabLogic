# Sparkplug B узел

Делает плату Sparkplug-узлом: при подключении к брокеру отправляет `NBIRTH` со всеми метриками, затем
`NDATA` с теми, что изменились, а при обрыве связи брокер сам публикует `NDEATH` (will-сообщение).
Нужен блок «MQTT клиент» (`mqtt`) и сеть; сам узел брокера не настраивает.

- `group` и `node` — идентификаторы в топиках `spBv1.0/<group>/<тип>/<node>`;
- `en` — разрешение (при `false` узел не объявляется);
- выход `online` — узел объявлен.

Метрики задают блоки «Sparkplug метрика» (`sparkplug_metric`): имя и значение. До 12 метрик, имя до 32 символов.

- Метка времени в `NBIRTH` и `NDATA` ставится, только если на плате есть время — нужен блок `ntp`; без него
  пакеты идут без метки.
- `bdSeq` после перезагрузки платы начинается с 0.
- `Node Control/Rebirth` объявляется в `NBIRTH`, но команды `NCMD` пока не принимаются.
Работает только в режиме модулей (мастер-прошивка); в обычном скетче блок ничего не делает.
