# Modbus TCP Master

Опрашивает по Modbus TCP одно устройство (сервер) по `ip` и `port`. На нём опрашиваются
ведомые (Unit ID), добавленные под блоком в левой панели: устройство — «Modbus: slave у master»,
тег — «Modbus: тег». Число ведомых ограничено параметром «Макс. slave» (`slaves`, по умолчанию 4,
до 32): чем больше, тем больше ОЗУ на плате. Работает через блок «Wi-Fi клиент» (`net = "wifi"`)
или «Ethernet» (`net = "ethernet"`) — нужный блок обязателен.

Значение тега, подключённое к выходу, читается с устройства; подключённое ко входу — пишется
на ближайшем опросе. Направление задаёт связь, см. «Modbus: тег».
Один регистр — целое 16 бит; `float` занимает два регистра подряд.

Адрес и порт каждого slave можно задать в левой панели под master; пустой адрес или порт 0 — как у master.

Другое устройство (сервер) обычно собрано на блоке «Modbus TCP Slave».
