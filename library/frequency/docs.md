# Частота

Измеряет частоту импульсов на выводе `pin`, от 1 Гц до 40 кГц: датчики оборотов, расходомеры с
импульсным выходом. Значение обновляется раз в `window`.

**Выходы.**
- `hz` — частота, Гц.
- `count` — всего импульсов с запуска (32 бита, заворачивается).
- `ok` — true, если счётчик открыт. Если нет, `ok = false`, блок раз в секунду пробует снова.

**Как считается.** Ниже примерно 1 кГц плата замеряет время между фронтами, и частота берётся по
периоду: она точна при любом окне и даже при одном импульсе за окно. Выше — по числу импульсов за
окно (точность тем выше, чем длиннее окно). Если импульсов нет дольше окна и двух последних
периодов, `hz` становится 0.

**Параметры.**
- `pin` — вывод импульсов (класс «вход»).
- `edge` — по какому перепаду считать период: нарастающий или спадающий.
- `window` — окно обновления, 10 мс…60 с (по умолчанию 1 с). Короткое окно — быстрее отклик, но
  на высокой частоте грубее значение.
- `filter` — фильтр, мкс: импульсы короче не считаются (0 — без фильтра).

**Пределы.**
- ESP32: аппаратный счётчик PCNT, до 40 кГц, не больше 8 счётчиков на плату. Аппаратный фильтр —
  не больше 12 мкс.
- ESP32-C3: счёт в прерываниях GPIO, без потерь до 50 кГц (замер без Wi-Fi: до 100 кГц); частые импульсы нагружают единственное ядро.
- Механические контакты требуют RC-цепочки на входе.
- После перезагрузки платы `count` начинается с 0; чтобы сохранить его, подключите к блоку
  «Сохранение во флеш».

Пример: `examples/flow_meter`.

```toml
[[block]]
id = "rpm_sensor"
type = "frequency"
pin = 34
window = "500ms"
```
