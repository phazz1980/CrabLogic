# ШИМ-выход

Управляет яркостью светодиода, скоростью вентилятора и т. п. Вход `in` —
заполнение в процентах, 8 бит разрешения, частота по умолчанию ядра ESP32.

```toml
[[block]]
id = "dimmer"
type = "pwm_out"
pin = 25
```

Параметр «при аварии» (`on_fault`) работает, когда схема залита модулем на мастер-прошивку: если модуль
упал или его выгрузили, мастер останавливает ШИМ (`0`, по умолчанию, на выводе низкий уровень), включает
100 % (`1`) или оставляет как есть (`2`, «держать»). Подробнее — [выходы при аварии модуля](help:build).
