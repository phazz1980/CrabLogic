# Быстрый счётчик

Считает импульсы на выводе `pin` быстрее шага схемы: расходомеры, счётчики продукции, датчики
оборотов. Счёт ведёт сама плата, схема только читает накопленное число раз за шаг.

**Вход.** `reset` — пока true, счёт держится на нуле.

**Выходы.**
- `count` — накопленное число импульсов (32 бита со знаком; при переполнении заворачивается через
  границу, а не останавливается).
- `ok` — true, если счётчик открыт. Если нет (вывод занят, счётчики кончились, мастер без этой
  функции), `ok = false`, `count` не меняется, а блок раз в секунду пробует открыть счётчик снова.

**Параметры.**
- `pin` — вывод импульсов (класс «вход»).
- `edge` — какие перепады считать: нарастающий, спадающий, оба.
- `direction` и `dir_pin` — считать вверх и вниз: 1 на выводе `dir_pin` — вверх, 0 — вниз. Пока
  `direction` выключен, вывод направления не занимается.
- `filter` — фильтр, мкс: импульсы короче не считаются (0 — без фильтра).

**Пределы.**
- ESP32: аппаратный счётчик PCNT, до 40 кГц, не больше 8 счётчиков на плату (Быстрый счётчик,
  Частота и Энкодер делят их между собой). Аппаратный фильтр — не больше 12 мкс: большее значение
  работает как 12.
- ESP32-C3: счёт в прерываниях GPIO, без потерь до 50 кГц (замер без Wi-Fi: до 100 кГц); частые импульсы
  нагружают единственное ядро: при 50 кГц прерывания занимают около половины его времени.
- Механические контакты (кнопки, герконы) дают дребезг, который короткий фильтр не гасит:
  ставьте RC-цепочку на входе.
- После перезагрузки платы счёт начинается с 0. Чтобы сохранить его, подключите `count` к блоку
  «Сохранение во флеш».

Пример: `examples/flow_meter`.

```toml
[[block]]
id = "flow"
type = "fast_counter"
pin = 27
edge = 0
filter = 5

[[link]]
from = "stop_button.out"
to = "flow.reset"
```
