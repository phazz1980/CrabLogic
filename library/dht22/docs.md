# DHT22

Читает температуру и влажность с датчика DHT22 (AM2302) раз в `period`.
Первое измерение — через `period` после включения, до него выходы равны 0,
`ok = false`. При ошибке чтения `ok` становится false, а значения хранят
последнее удачное измерение.

На Rust-мастере блок — драйвер `block.wasm` (исходник `drivers/dht22`): мастер даёт стартовый импульс и замеряет ответ датчика (`pulse_read`, около 5 мс аппаратным приёмником RMT: прерывания не запрещаются, лист на это время ждёт), драйвер раскладывает 40 бит и проверяет контрольную сумму. Первое измерение идёт сразу после включения. В симуляции на ПК выходы равны 21,5 °C, 45 % и `ok = true`.

Нужны библиотеки «DHT sensor library» и «Adafruit Unified Sensor» —
`crablogic build` и мастер-прошивка ставят их сами. Пример: `examples/sensors`.

```toml
[[block]]
id = "air"
type = "dht22"
pin = 15
```
