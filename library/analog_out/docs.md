# Аналоговый выход

Выдаёт напряжение 0…3,3 В на вывод с ЦАП. Вход `in` — код ЦАП 0…255 (вне диапазона код
ограничивается): 0 — 0 В, 255 — около 3,3 В, шаг около 13 мВ (8 бит).

Только ESP32: ЦАП есть на выводах GPIO25 и GPIO26. У ESP32-C3 и других плат без ЦАП проверка схемы
выдаёт ошибку.

```toml
[[block]]
id = "level"
type = "analog_out"
pin = 25
```

Выход слабый (высокое выходное сопротивление): нагрузку подключайте через повторитель на
операционном усилителе, преобразователь 0…10 В или 4…20 мА, а не напрямую.

Параметр «при аварии» (`on_fault`) работает, когда схема залита модулем на мастер-прошивку: если модуль
упал или его выгрузили, мастер выдаёт 0 В (`0`, по умолчанию), оставляет прежнее напряжение (`1`,
«держать») или выдаёт код из параметра «значение при аварии» (`2`, `fault_value`, 0…255). Подробнее —
[выходы при аварии модуля](help:build).

Блок не годится для функций аварийной защиты (аварийный стоп и т. п.): такие функции делаются только
аппаратно.
