# Значение на экране

Число на экране дисплея. Вход `in` — значение из схемы; виджет — такой же тег, как веб-виджет: его перетаскивают на лист и соединяют со схемой.

- `display`, `screen`, `x`, `y`, `w`, `h` — как у «Текст на экране».
- `format` — шаблон вывода, например `T=%v °C`, где `%v` — место числа; пусто — только число.
- `decimals` — знаков после запятой; `unit` — единица после числа.
- `font` — 8 или 16 пикселей (только OLED).
