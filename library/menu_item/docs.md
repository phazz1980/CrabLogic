# Пункт меню

Пункт меню дисплея. Как веб-виджеты, хранится в `web.toml` проекта и создаётся в конструкторе; на лист не ставится.

- `menu` — имя блока «Меню», `parent` — имя пункта-подменю, в котором лежит пункт (пусто — верхний уровень), `order` — место среди пунктов одного уровня.
- `kind` — вид: `submenu` (подменю), `number` (число), `bool` (переключатель), `choice` (выбор из списка), `action` (действие — импульс), `view` (просмотр значения).
- `caption` — название в меню.
- `var` — переменная схемы. Тип должен подходить виду: число — `int` или `float`, переключатель и действие — `bool`, выбор — `int` (номер варианта с нуля). Иначе проверка схемы выдаёт ошибку.
- `min`, `max`, `step`, `unit` — пределы, шаг и единицы числа.
- `choices` — варианты выбора через точку с запятой, например `Выкл;Авто;Ручной`.

Чтобы уставка переживала перезагрузку, включите у её переменной сохранение (`retain`).
