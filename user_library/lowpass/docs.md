# Фильтр сглаживания

Экспоненциальное сглаживание (фильтр нижних частот первого порядка): выход плавно стремится ко входу.
Каждый цикл: `k = dt / (tau + dt)`, `out += k * (in - out)`, где `dt` — время с прошлого цикла.

| Порт | Тип | Что это |
| --- | --- | --- |
| `in` (вход) | float | сглаживаемое значение (целое приводится к дробному) |
| `out` (выход) | float | сглаженное значение |
| `tau` (параметр) | float, мс | постоянная времени; по умолчанию 1000, не меньше 1 |

Через время `tau` выход проходит около 63 % разницы. До первого цикла и после запуска выход равен 0 и
затем растёт к входу. Блок помнит предыдущее значение выхода.

Исходник: `blocks_src/lowpass/src/lib.rs` (работает только с мастером на Rust).

```toml
[[block]]
id = "lp"
type = "lowpass"
tau = 500.0
```
