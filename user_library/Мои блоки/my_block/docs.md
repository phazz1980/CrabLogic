# Новый блок

Заготовка пользовательского блока: копирует логический вход `in` на выход `out` без изменений.
Без памяти, выход зависит только от текущего входа. Замените код в `blocks_src/my_block/src/lib.rs`,
чтобы сделать свою логику.

| Порт | Тип | Что это |
| --- | --- | --- |
| `in` (вход) | bool | входной сигнал |
| `out` (выход) | bool | равен `in` |
