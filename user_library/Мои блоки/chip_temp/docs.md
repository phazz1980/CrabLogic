# Температура чипа

Читает встроенный датчик температуры кристалла (функция `temperatureRead()`).
Работает на ESP32-C3, S2, S3, C6. На обычном ESP32 датчика нет: `ok = false`, `temp = 0`.

Показывает температуру самого чипа, а не воздуха: погрешность несколько градусов,
при работе Wi-Fi/BLE значение выше окружающей. Годится для контроля перегрева.

Выход `temp` — °C, `ok` — замер выполнен. Параметр `period` — как часто опрашивать.

```toml
[[block]]
id = "chip"
type = "chip_temp"
```
