# План: теги Modbus slave по адресу и типу

## Решения, добавленные после обсуждения
- Тег — скрытый блок `modbus_write` («из схемы», master читает) или `modbus_read` («в схему», master пишет),
  как темы MQTT: создаётся в панели, на лист попадает перетаскиванием. Формат проекта прежний:
  параметры `table`, `kind`, `reg`; имя тега — id блока (по умолчанию `reg_<адрес>`).
- Дыры в адресах остаются при удалении тега. Размер таблицы = самый дальний тег (адрес + размер): подсчёт без
  дыр потребовал бы отображения адресов в хранилище и усложнил мастер (таблицы — массивы по адресу).
- Порядок слов float: булев параметр `swap` блоков чтения/записи (CDAB); по умолчанию ABCD, как сейчас.

## Затронутые места
- `crab-core/src/modbus_tags.rs`: подсчёт занятых адресов (int 1, float 2, bool 1 бит), следующий свободный,
  размеры таблиц по тегам, поиск пересечений; общий для панели, проверки и генератора.
- `crab-core/src/check/`: ошибка «адрес занят» (теги одной таблицы пересекаются; Coil/Discrete только bool,
  Holding/Input только int/float).
- `library/modbus_read|write/block.toml`: параметр `swap`; `modbus_tcp_slave` и `modbus_rtu_slave`: убрать
  параметры `holding`, `input`, `coils`, `discrete`; `docs.md` всех четырёх блоков.
- `crab-codegen/src/wasm/modbus.rs`: размеры таблиц слейва берутся из тегов (коды настроек 8–11 прежние, мастер
  не меняется); флаг `swap` в операции (бит 10 селектора `b`).
- `firmware/master-rs/src/modbus.rs` (+ `board/modbus.rs`): чтение/запись float с обменом слов по биту 10;
  тесты на ПК. Мастер придётся перезалить.
- `crab-sim`: симуляция таблиц по тегам и `swap`.
- `crab-editor`: `modbuspanel.rs` — таблица тегов слейва (имя, таблица, тип, адрес, направление, «слова
  наоборот», удалить), «+» подставляет следующий свободный адрес; пересечения подсвечиваются; перетаскивание на лист.
  Кнопки «+ Чтение/Запись» заменяются таблицей тегов.
- `crab-cli/src/bench/stands.rs`: стенд Modbus TCP использует новый способ.
- `examples/modbus_wifi`, `examples/modbus_ethernet`, `examples/modbus_rtu`: перевести на теги; справка
  `help/03-schema.md`, `help/02-editor.md`, «Что нового».

## Риски
- Мастер-прошивка меняется (бит `swap`): нужен замер скорости и ОЗУ по правилам проекта.
- Размер таблицы больше не задаётся: далёкий адрес (например, 9999) занимает ОЗУ; ввести разумный предел
  (проверка размера по оценке ОЗУ платы).
- Блоки, где `swap` не задан, ведут себя как раньше.
