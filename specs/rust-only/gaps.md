# Пробелы Rust-мастера (замер `crablogic audit-rust`)

Замер 12.11.2026, после переноса АЦП, ШИМ, retain, UART, PCF8574, Modbus, веб-интерфейса и драйверов
DS18B20/DHT22. Возможности мастера — `MASTER_CAPS` генератора (все есть в `MODCAPS` Rust-мастера, плюс
`modbus`, `web`).

**Итог: 0 из 166.** Все блоки библиотеки (каждый в отдельном проекте: входы питаются константами своего типа,
параметры без значения получают пробные, веб-виджеты стоят на странице блока Wi-Fi) и все примеры `examples/`
(со своими блоками и платами) собираются модулями, и мастеру хватает возможностей.

Найдено и исправлено по ходу замера:
- `scale_table`: значение по умолчанию записано строкой C (`"0:0;50:20;100:100"` с кавычками) — генератор модуля
  получал ноль точек и падал (выход за границы). Разбор точек теперь пропускает кавычки, таблица из меньше чем
  двух точек — ошибка генерации, а не паника.

Чего замер не видит (проверяется отдельно, этап B и G2):
- работает ли модуль на плате так же, как C++-скетч (это тесты `crab-sim` и проверка на C3 COM5 / ESP32 COM10);
- блоки, которые собираются, но в Rust-мастере сделаны не полностью: поиск сетей и применение формы сети
  на веб-странице (вопрос 35), отличия Modbus (вопрос 34);
- платы кроме ESP32 и ESP32-C3 (вне перехода).
