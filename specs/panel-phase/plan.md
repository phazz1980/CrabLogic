# План: выбор фазы на 400 В

## Формат

`Device.conductors: Vec<String>` (`serde(default, skip_serializing_if = "Vec::is_empty")`) —
проводники, которые берёт устройство, по порядку шины: `["L2"]`, `["L3","N"]`, `["L1","L3"]`.
Пусто — по умолчанию (см. спеку). Только на 400 В; на других питаниях поле не учитывается.

## crab-core

- `Supply::pole_range`: `Ac400 → (1, 4)` (редактор и `terminals_of` берут диапазон отсюда).
- `panel.rs`: поле `conductors`; `rename`/`remove` его не касаются.
- `check/panel.rs`: `conductors` только на 400 В (иначе предупреждение «фаза задана, но питание не
  400 В»); имена из `Supply::lines()` без повторов; у аппарата с полюсами — число равно полюсам;
  ошибка — если имя не из шины.

## crab-schematic

- `nets.rs`: `fn conductors(panel, feeder, device) -> Vec<&'static str>` — эффективные проводники:
  - на 400 В у аппарата с полюсами: свои `conductors` (если заданы и годятся), иначе по умолчанию
    по числу полюсов (1 → `L1`, 2 → `L1 N`, 3 → `L1 L2 L3`, 4 → все);
  - у остальных (нагрузка, блок питания, двигатель, клеммник): свои `conductors`, иначе как у
    питающего; на 400 В одиночная фаза дополняется `N`;
  - доступно устройству: проводники питающего ∪ `N` (мимо от шины); недоступное отбрасывается;
  - на других питаниях и в домене 24 В — как сейчас (первые по полюсам).
  Результат кладётся в `Nets.conductors: BTreeMap<String, Vec<String>>` (для листа и редактора).
- Провода силовой цепи: для имени `name` с индексом `i` в списке устройства:
  `from = out_pin(up, позиция name у up, name)`; если у `up` его нет (`N` мимо) — от ввода
  (`out_pin(feed, _, "N")`) или `EXTERNAL`. `to = in_pin(t, i, name)` — клеммы по позиции:
  1P на `L2` — клеммы `1-2`.
- `terminals_of` — по эффективным проводникам (имена у нагрузки).

## crab-schematic/power.rs

- Номер линии полюса `k` устройства — по имени из `nets.conductors[d]` (`line_of(name)`), не `k`:
  спуск с шины `bus_y(line)`, `bus_end[line]`; подписи и клеммы — имена из списка устройства.
- Провод ребра, идущий от ввода, когда родитель — не ввод (`N` мимо контактора), рисуется
  спуском с шины, как `from_bus`.
- `riser_from(k)`: линия `k` поднимается от последнего устройства ввода, у которого она есть в
  списке.

## crab-editor

- Свойства аппарата с полюсами на 400 В при 1–2 полюсах: «Фаза» — список (1P: `L1`/`L2`/`L3`;
  2P: `L1+N`, `L2+N`, `L3+N`, `L1+L2`, `L1+L3`, `L2+L3`). У нагрузки, двигателя, блока питания под
  трёхфазным аппаратом: «Фазы» — «Как у питающего» и варианты из доступных проводников.
- Смена полюсов сбрасывает `conductors`, если число не совпало.

## Риски

- Ребро с проводами от двух родителей (`N` мимо) — power.rs считает родителя по первому проводу;
  `N` идёт последним, родитель — аппарат. Проверить тестом.
- Номера проводов: `N` мимо в одной сети с шиной `N` — общий номер (проверить перечнем).
