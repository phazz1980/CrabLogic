# Электрическая документация щита из проекта

## Цель

Из проекта CrabLogic получать комплект электрической документации на щит: принципиальные схемы
(управление и силовая часть), перечень клемм и проводов, спецификацию. Оформление — по IEC
(символы IEC 60617, обозначения изделий по IEC 81346/61346: `-Q1`, `-K1`, `-X1`, перекрёстные ссылки
листов). О сертификации не заявляем. Приоритет — срочный.

Плата и логика уже знают входы, выходы, типы датчиков и реле; дублировать их в сторонней САПР не нужно.

## Сценарии

1. Пользователь добавляет в проект «устройства щита»: ввод питания, автомат, УЗО, блок питания,
   контактор/реле, двигатель, нагрузка, клеммник, датчик. Устройство привязывается к выходу или входу
   проекта (выход `pump` → катушка `-K1`, контакты `-K1` → двигатель `-M1`).
2. Кнопка «Собрать документацию» создаёт листы: титульный, силовая часть, цепи управления (плата,
   входы, выходы), клеммники, перечень проводов, спецификация.
3. Листы лежат в архиве проекта (как `boards.pdf`) и экспортируются в PDF; таблицы — ещё и в CSV.
4. Изменили схему или привязку — документация пересобирается, номера клемм и проводов остаются
   стабильными у неизменившихся цепей.
5. Позже: ручная правка раскладки листа; экспорт в `.qet` и DXF.

## Критерии готовности (первая версия)

1. Пример `examples/` (насос): документация собирается командой CLI и из редактора, PDF открывается,
   символы и обозначения по IEC.
2. Силовая часть: ввод → автомат → контактор → двигатель, защитное заземление, видны номиналы.
3. Каждый вход и выход проекта есть в схеме управления и в перечне клемм: плата, вывод, клемма, цепь, провод.
4. Перекрёстные ссылки: у катушки указаны листы и колонки её контактов, у контакта — катушка.
5. Проверка: выход без устройства, устройство без привязки, занятая клемма, повторное обозначение,
   несовместимые типы сигнала — ошибки по-русски, как в `crablogic check`.
6. Нумерация клемм и проводов детерминирована: одинаковый проект даёт одинаковый результат.
7. Спецификация: количество и тип изделий, сгруппированные; поле для артикула.
8. Тесты на ПК, пример, справка (`help/`), `docs.md` новых блоков/устройств.

## Вне задачи

Универсальный редактор любых электросхем, расчёт сечений и токов КЗ, 3D-компоновка шкафа,
каталоги производителей (артикулы вводятся вручную), оформление по ГОСТ/ЕСКД, функции аварийной
защиты (по правилам проекта — только аппаратно, в справке говорим прямо).

## Вопросы

(ответы пользователя 20.11.2026: документация к проекту, IEC, силовая часть нужна, срочно)

Ответы 20.11.2026:
1. Силовая часть задаётся вкладкой «Щит»: список устройств с привязкой, линии строит генератор
   (вид показан пользователю, ждёт подтверждения).
2. Формат листа — A3 альбомный (решение 21.11.2026 по ГОСТ IEC 61082-1, 5.4; до этого A4 по образцу пользователя) с
   координатной сеткой: зоны по 25 мм: 1–15 по горизонтали (сверху и снизу), A–L без I и O по вертикали (слева и справа);
   штамп внизу. Цепи идут сверху вниз; перекрёстные ссылки — «/лист.зона» (`/3.C5`: косая черта,
   лист и зона), длинные схемы переносятся на следующий лист.
3. Язык подписей на листах — переключаемый (через `i18n`).
4. Питание первой версии: 24 В DC, 230 В 1ф, 400 В 3ф.
5. Сначала PDF со схемами (силовая часть и управление), таблицы и CSV следом.
