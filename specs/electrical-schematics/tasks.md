# Задачи: электрическая документация щита

Порядок рассчитан на то, чтобы первый PDF со схемой был на шаге 4.

- [x] **1. Модель.** `panel.toml` в `crab-core` (структуры, чтение/запись в архив и папку, старые
  проекты без файла); раздел в `Архитектура и план.md`.
  Проверка: тест круговой записи и чтения; проект без `panel.toml` читается без изменений.
- [ ] **2. Проверка щита.** Выход без устройства, устройство без привязки, повторное обозначение,
  занятая клемма, несовместимый сигнал; `crablogic check` показывает ошибки по-русски.
  Проверка: тесты на каждую ошибку, ошибки без паник.
- [ ] **3. Граф цепей и нумерация.** Цепи, номера клемм и проводов, детерминированность и
  сохранение выданных номеров.
  Проверка: тест «одинаковый проект — одинаковые номера», тест стабильности при добавлении устройства.
- [ ] **4. Символы IEC и силовой лист.** Крейт `crab-schematic`: символы (ввод, автомат, УЗО, БП,
  контактор, реле, двигатель, нагрузка, клемма, PE), раскладка по колонкам A4 книжный, вывод Typst,
  общий хелпер с `crab-pdf`; `crablogic panel`.
  Проверка: PDF примера насоса открывается, силовая часть читаема (снимок разметки в тестах).
- [ ] **5. Лист управления.** Плата с клеммами, входы, выходы, датчики, катушки; перекрёстные ссылки
  лист/колонка.
  Проверка: каждый вход и выход проекта есть на листе; ссылки совпадают с раскладкой (тест).
- [ ] **6. Перенос и титул.** Перенос длинных схем на следующий лист, титульный лист, штамп, нумерация листов.
  Проверка: тест на проект, не помещающийся в один лист.
- [ ] **7. Клеммник, провода, спецификация.** Таблицы на книжных листах, CSV; поле артикула.
  Проверка: CSV читается обратно, итоги спецификации совпадают с числом устройств.
- [ ] **8. Язык ru/en.** Таблицы строк подписей, параметр `--lang`.
  Проверка: тест, что обе таблицы содержат одни ключи; PDF на двух языках.
- [ ] **9. Режим «Щит» в редакторе.** Вкладки «Логика» / «Щит» над центром; слева дерево устройств
  по образцу левой панели, меню «Найти…/Свойства…/Удалить из проекта»; в центре предпросмотр листов
  (страницы, язык, «Собрать PDF»); справа свойства и привязка; `panel.pdf` в архиве при сохранении.
  Режим «Логика» без изменений.
  Проверка: ручная в редакторе (переключение режимов не теряет выделение и масштаб листа логики),
  тесты модели правок.
- [ ] **10. ИИ и MCP.** Команды: прочитать щит, добавить устройство, привязать, собрать.
  Проверка: тесты общего набора команд.
- [ ] **11. Пример, справка, новости.** `examples/pump` дополняется щитом (230 В, автомат, контактор,
  двигатель, 24 В); страница `help/panel.md` (+ перевод), запись в новостях.
  Проверка: `crablogic panel examples/pump` даёт PDF; ссылки справки ведут в программу.
- [ ] **12. Сверка с критериями спеки.** Пройти критерии 1–8, дописать недоделанное сюда;
  сообщить, что проверено, а что нет.
  В конце шага: `cargo fmt`, `cargo clippy --all-targets`, `cargo test`.
