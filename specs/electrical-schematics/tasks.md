# Задачи: электрическая документация щита

Порядок рассчитан на то, чтобы первый PDF со схемой был на шаге 4.

- [x] **1. Модель.** `panel.toml` в `crab-core` (структуры, чтение/запись в архив и папку, старые
  проекты без файла); раздел в `Архитектура и план.md`.
  Проверка: тест круговой записи и чтения; проект без `panel.toml` читается без изменений.
- [x] **2. Проверка щита.** Выход без устройства, устройство без привязки, повторное обозначение,
  занятая клемма, несовместимый сигнал; `crablogic check` показывает ошибки по-русски.
  Проверка: тесты на каждую ошибку, ошибки без паник.
- [x] **3. Граф цепей и нумерация.** Цепи, номера клемм и проводов, детерминированность и
  сохранение выданных номеров.
  Проверка: тест «одинаковый проект — одинаковые номера», тест стабильности при добавлении устройства.
- [x] **4. Символы IEC и силовой лист.** Крейт `crab-schematic`: символы (ввод, автомат, УЗО, БП,
  контактор, реле, двигатель, нагрузка, клемма, PE), раскладка по колонкам A4 альбомный с зонами, вывод Typst,
  общий хелпер с `crab-pdf`; `crablogic panel`.
  Проверка: PDF примера насоса открывается, силовая часть читаема (снимок разметки в тестах).
- [x] **5. Лист управления.** Плата с клеммами, входы, выходы, датчики, катушки; перекрёстные ссылки
  лист/колонка.
  Проверка: каждый вход и выход проекта есть на листе; ссылки совпадают с раскладкой (тест).
- [x] **6. Перенос и титул.** Перенос длинных схем на следующий лист, титульный лист, штамп, нумерация листов.
  Проверка: тест на проект, не помещающийся в один лист.
- [x] **7. Клеммник, провода, спецификация.** Таблицы на листах A4 альбомных, CSV; поле артикула.
  Сделано: `crab-schematic/src/tables.rs`, `crablogic panel --csv <папка>`, тесты `tests/tables.rs`
  (CSV читается обратно, сумма спецификации = числу устройств, шапка на каждом листе длинной таблицы).
  Проверка: CSV читается обратно, итоги спецификации совпадают с числом устройств.
- [x] **7а. Соответствие ГОСТ IEC 61082-1-2014** (решения и таблица сверки — `gost-61082.md`).
  Шаги: (1) геометрия — модуль M = 2,5 мм (10 u), формат A3 альбомный по умолчанию (A4 — флаг
  `--format a4`), зоны шагом 10M с буквами без I и O, линии 0,25 / 0,5 мм, высоты текста из ряда;
  (2) символы, выводы и шаги листов — на сетку 1M/0,5M, ссылки `/N.зона` и `/.зона`;
  (3) питание L1, L2, L3, N, PE и L+, M, L-, штрихпунктир ограничительных рамок, блок ISO 7200,
  номера проводов и выводов рядом с линией по 7.1.3.5; (4) тесты на константы геометрии и формат ссылок.
  Проверка: тесты (ряды линий и текста, кратность сетке, отсутствие I и O, формат ссылок),
  снимок разметки в SVG-просмотре.
  Сделано 21.11.2026: A3 (A4-флага пока нет), M = 2,5 мм, зоны 15×11 по 25 мм без I и O, линии 0,25/0,5 мм,
  текст 2,5/3,5/5 мм, символы и выводы на сетку 0,5M, номера проводов вдоль линии слева (поворот 90°),
  ссылки `/лист.зона`, обозначение питания по IEC 61293 на силовом листе; тесты в `doc.rs`.
  Остатки закрыты тем же днём: `--format a3|a4` (`Page`, `Format`, `build_document_in`), блок штампа с форматом,
  `/.зона` для ссылок на том же листе, шины `L+` и `M` на листе постоянного тока, тест «все вызовы тела
  внутри рамки на A3 и A4» (`tests/format.rs`).
  Осталось (нужно решение пользователя или данные, которых нет в модели):
  - (сделано) шрифт: OpenGost Type B (ГОСТ 2.304 тип Б, OFL-1.1) встроен в `crablogic-pdf`
    (`crates/crab-pdf-render/fonts/`, файл взят из релиза v0.4.0 с Codeberg `nadevko/opengostfonts`, без
    изменений); кегль = высота заглавных × 1,7 (у шрифта заглавные 1000/1700 кегля); жирного начертания нет —
    у «жирных» подписей добавлен контур 0,3 u; `osifont` не взят: в нём убрана поддержка русского;
  - блок ISO 7200: дата и разработчик — в проекте нет таких полей (дата ломает одинаковый результат сборок);
  - штрихпунктир ограничительных рамок: в модели щита нет группировки устройств (шкаф, секция);
  - имена `L+`, `M`, `L-` только на шинах листа; клеммы устройств остаются `+24V`, `0V` (сигналы платы).
- [x] **8. Язык ru/en.** Подписи через `Lang::pick(ru, en)` рядом с кодом (отдельной таблицы строк нет:
  пара строк стоит в одном месте, пропустить перевод нельзя), параметр `--lang`.
  Сделано: `tests/lang.rs` — в английских листах и таблицах нет кириллицы (A3 и A4, все виды устройств,
  три питания), обе версии дают одинаковые листы, провода и места, подпись штампа на своём языке;
  английский вариант проверен и на вписывание в рамку (`tests/format.rs`); PDF на двух языках собираются.
  Проверка: тест, что обе версии подписаны полностью; PDF на двух языках.
- [x] **9. Режим «Щит» в редакторе.** Вкладки «Логика» / «Щит» над центром; слева дерево устройств
  по образцу левой панели, меню «Найти…/Свойства…/Удалить из проекта»; в центре предпросмотр листов
  (страницы, язык, «Собрать PDF»); справа свойства и привязка; `panel.pdf` в архиве при сохранении.
  Режим «Логика» без изменений. Подзадачи (план — `plan.md`, раздел «Редактор»):
  - [x] **9а. Операции рисования.** `Canvas` кроме Typst-текста хранит список `Op` (линия, штриховая, прямоугольник,
    круг, точка, текст, повёрнутый текст); `Sheet.ops`, `Document::frame_ops(лист)`; предпросмотр рисует их же.
    Проверка: тест — число операций совпадает с вызовами в Typst-разметке, тексты те же.
  - [x] **9б. Правки щита с отменой.** `Doc` хранит щит в снимке отмены; `edit_panel`; правка щита не пересобирает
    прошивку (`revision` не растёт), но ставит `dirty`.
    Проверка: тесты отмены и возврата правки щита, `revision` не меняется.
  - [x] **9в. Режим и панели.** `EditorApp.mode`, вкладки, дерево устройств (группы по видам, «+», плоские строки,
    меню), свойства справа (обозначение, вид, параметры, артикул, привязка, `load`), диагностика `check_panel`.
    Проверка: тесты модели правок; вручную в редакторе.
  - [x] **9г. Предпросмотр листов.** Лист на холсте egui по `Op`, переход по листам, язык, формат, «Найти на листе»
    (переход и подсветка зоны), список ошибок щита.
    Проверка: вручную; тест пересчёта документа при правке щита.
  - [x] **9д. PDF.** Кнопка «Собрать PDF» (в фоне), `panel.pdf` в архиве при сохранении, если щит не пуст.
    Проверка: тест архива с `panel.pdf`; ручная проверка кнопки.
  - [x] **9е. Справка и переводы.** Страница `help/18-panel.md` (перевода справки на другие языки пока нет; строки интерфейса переведены в `i18n/en.json`), строки через `i18n::tr`.
    Проверка: тест справки (ссылки ведут в программу), все строки в таблице переводов.
  - **Не проверено глазами (21.11.2026):** окна режима «Щит» (вкладки, дерево, предпросмотр, кнопка «Собрать PDF») собраны и покрыты тестами модели, но в запущенном редакторе не открывались; переводы строк режима есть только в `en.json` (zh/es/hi/bn позже).
- [x] **10. ИИ и MCP.** Команды: `get_panel`, `add_panel_device`, `set_panel_device` (привязка, переименование), `remove_panel_device`, `set_panel_supply`, `build_panel` (`crab-ai/src/panel.rs`); в редакторе щит едет через `Msg::Edit`.
  Проверка: тесты общего набора команд.
