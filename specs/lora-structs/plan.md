# План: LoRa со структурами

## Идея
Структуры уже лежат в памяти модуля слотами по 4 байта на поле (`crab-codegen/src/wasm/structs.rs`) и в симуляции
(`crab-sim/src/structs.rs`). Блоки обмена (`lora_point`, `lora_centre`) кода не выдают: их обслуживает драйвер модема через
дополнительные ячейки (`wasm/lora.rs`). Если у блока выбрана структура, значения идут в ячейки драйвера и из них
не через порты блока, а через слоты структуры. Кадр и драйвер (`drivers/lora_e220`) не меняются: типы и порядок значений —
типы и порядок полей.

## Затронутые места
- `library/lora_point`, `library/lora_centre` (`block.toml`): параметры `cmd_struct`, `ans_struct` (строки с именем
  структуры), порты значений скрываются, когда параметр задан (`when`), `docs.md`.
- `crab-core`: `check/lora.rs` — структура есть, поля только bool/int/float, не больше 10, структура указана не наполовину
  (обе или ни одной — решить при проверке), сообщения на русском; справка об ошибках.
- `crab-codegen/src/wasm/lora.rs`: `types` берёт типы из структуры; `lora_inputs` читает слоты структуры в ячейки,
  `lora_outputs` пишет ячейки в слоты; общий доступ к слотам через `struct_mem` (структура общая для листов — склейка
  листов уже есть). Ограничение: блок обмена и модем на одном листе, как сейчас.
- `crab-sim`: обмен LoRa в симуляции (имитация эфира) читает и пишет структуру блока так же, как порты.
- `crab-editor`: диалог блока обмена (список структур в параметре), ничего более; блок не показывает порты значений.
- Пример `examples/lora_structs` (центр и ведомый), тесты в `crab-codegen/tests/library_modules.rs`, `crab-core/tests/lora.rs`.
- Справка: `help/16-lora.md`, `help/17-arrays.md`, `help/09-news.md`, `Архитектура и план.md` (строка).

## Риски
- Структура общая для листов центра: блок обмена и модем на одном листе, структура на другом → склейка листов в один
  модуль (уже работает, но проверить вместе с LoRa).
- Хеш типов в CRC: он считается из `types(...)`; при выводе из структур нужно совпадение порядка со вторым концом.
- Запись структуры в одном шаге с «Структура: запись» схемы: побеждает последняя запись за такт (сказано в справке).
- Не проверено на железе (две платы): помечается в `tasks.md`.
