# Задачи: карта SD

**Отложено 15.11.2026:** нет карты microSD с переходником SPI для проверки на платах. План согласовать заново,
когда карта появится.

1. [ ] Мастер: `board/sd.rs` — настройка с модуля, хост драйверов SPI, монтирование в потоке `crab-sd`, повтор при
   отсутствии карты; `modcaps` `sd`; строка `sd …` в `info`. Проверка: плата с картой — `info` показывает готовность и
   свободное место; без карты — «нет карты», вставили — готова; размер мастера ESP32/C3.
2. [ ] Мастер: кольцевой буфер строк, запись по дням, `fsync` раз в 2 с, кольцо по свободному месту, счётчики.
   Проверка: хост-тесты (буфер, имя файла по дате, выбор файлов на удаление); на плате — файлы появляются.
3. [ ] Мастер: команды `sd ls`, `sd get`, `sd rm` (разбор в `protocol.rs` + хост-тесты).
4. [ ] Блоки `sd_card`, `sd_archive`, `sd_log` (+ `block.toml`, `docs.md`), генератор, тест сборки модуля
   (`library_modules.rs`), пример `examples/sd_archive`.
5. [ ] ПК: `crab-build/sd_files.rs`, `crablogic sd ls|get|pull` (USB и сеть), окно редактора. Тесты на поддельном мастере.
6. [ ] Проверка на платах: архив 10 значений/с и журнал; выдернуть/вставить карту на ходу; выдернуть питание во
   время записи; карта почти полна — удаляются старые дни; `late50/late100` с картой и драйвером SPI; скачивание по
   USB и по сети.
7. [ ] Справка, новости; `cargo fmt`, `clippy`, `test`; `crablogic bench` ESP32 и C3, строка в `bench/history.md`.
