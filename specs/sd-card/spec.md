# Карта SD: архив значений и журнал событий

## Цель

Шкаф автоматики хранит у себя историю: значения сигналов по времени (тренды) и журнал событий (аварии, смены
режимов, действия оператора). Данные переживают перезагрузку и пропажу питания, их можно забрать без остановки
схемы. Пункт 5 из `specs/hw-backlog.md`.

## Факты (15.11.2026)

- Обе платы — ESP32 и ESP32-C3, флеш 4 МБ, мастер занимает ~80 % раздела 2 МБ; FAT и драйвер SD есть в ESP-IDF
  (оценка: +30–40 КБ флеша мастера, 6–8 КБ кучи под буферы).
- Карта подключается по SPI (оба чипа) или SDMMC 1/4 бит (только ESP32, выводы фиксированы). Шина SPI уже есть у
  мастера (`board/bus.rs`, драйверы `block.wasm`); на ESP32 два хоста SPI (SPI2, SPI3), на C3 один (SPI2), и его же
  может занимать Ethernet W5500.
- Время на плате — блок NTP (без сети времени нет: метки — от включения).
- Правила платы (`CLAUDE.md`): шаг не ждёт флеш/карту — запись в фоновой задаче, ограниченная очередь, переполнение
  считается; отказ карты не роняет схему.

## Сценарии

1. Архив значений: блок получает несколько входов и период (например, 1 с) — строки «время; значения» копятся на
   карте по файлу в сутки.
2. Журнал событий: блок пишет строку текста по фронту входа (авария, пуск, смена уставки) с меткой времени.
3. Забрать данные: вынуть карту и открыть на ПК; без остановки шкафа — по сети или USB (см. вопросы).
4. Карта вынута, испорчена или полна: схема работает дальше, выход «карта готова» = 0, ошибки считаются и видны в
   отладке и журнале платы; вставили карту — запись продолжается сама.

## Критерии готовности (черновик)

1. Архив и журнал пишутся на ESP32 и C3; файлы открываются на ПК (Excel/Блокнот) с понятными столбцами.
2. Шаг схемы не опаздывает из-за записи: замер `late50/late100` с архивом 10 значений/с против без него.
3. Выдернуть карту на ходу, вставить обратно; выдернуть питание во время записи — плата стартует, карта читается,
   теряется не больше последнего периода сброса.
4. Очередь записи ограничена; переполнение (медленная карта) — счётчик потерянных строк, без зависаний.
5. Справка, `docs.md` блоков, пример в `examples/`, тест сборки модуля, замер `crablogic bench`.

## Вне задачи (черновик)

Чтение произвольных файлов с карты из схемы, рецепты/конфигурации с карты, обновление мастера с карты, шифрование,
SDMMC 4 бит (если выбираем SPI), графики архива в редакторе.

## Ответы пользователя (15.11.2026)

1. Пишем **архив значений и журнал событий** — два блока.
2. **CSV, файл на сутки, кольцом:** когда места мало, удаляются самые старые дни; запись не останавливается.
3. Забирать без извлечения карты — **командой `crablogic` и из редактора**, по USB или по сети (вход 4040 с паролем);
   веб-страница — не в этой задаче.
4. Подключение — **SPI на своих выводах** (оба чипа); шина общая с драйверами и W5500 (свой CS), на ESP32 — по
   возможности на своём хосте. SDMMC — вне задачи.
