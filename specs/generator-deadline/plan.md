# План: генератор по дедлайну

## Затронутые места

- `crates/crab-blocks/src/cpp.rs:410` — C++-вывод (Arduino/AVR); сейчас `% period`, при нулевом периоде деление на 0.
- `crates/crab-codegen/src/wasm.rs:1960` — WASM-вывод.
- Тесты: `crates/crab-sim/tests/wasm_emit.rs`, снимки C++ (`crab-blocks`/`crab-codegen`), фикстура `wasm_timers`.
- Справка: `library/generator/docs.md`, страница справки про таймеры/генераторы.

## Алгоритм (одинаков во всех трёх местах)
Состояние: `start` (i32 мс, начало текущей фазы), `phase` (0 = включено, 1 = выключено), `active`.
Каждый шаг при `en`:
1. Если не `active`: `active=1; phase=on; start=now; out=1` (при `time_on=0` см. краевые случаи).
2. `d = now - start` (i32, с переходом через ноль). Если `d < L(phase)` — ничего, выход прежний.
3. Иначе быстрый путь: `d1 = d - L(phase)`; если `d1 < L(другая фаза)` — переключить фазу,
   `start += L(старая фаза)`; `L` читается из параметров именно сейчас (смена времён с ближайшего переключения).
4. Иначе догонка (редко): `period = max(on+off,1)`, `r = d % period`; если `r < L(phase)` — фаза та же,
   `start = now - r`; иначе фаза другая, `start = now - (r - L(phase))`.
При `!en`: `active=0; out=0`.
Краевые: `time_off=0` → выход постоянно 1 пока `en`; `time_on=0` → постоянно 0; `L(phase)=0` обрабатывается
пропуском фазы без деления на 0.
Выход = `phase == on`.

## Риски
- Расхождение WASM/C++/sim на краях (ноль, переход `now` через 2^31, шаг > периода) — закрыть тестом сверки на сетке.
- Старые снимки C++ изменятся — пересоздать осознанно, проверив diff.
- Правки незакоммиченные в `wasm.rs` (чужие) — начинать после их коммита/stash.
