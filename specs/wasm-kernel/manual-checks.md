# Ручные проверки wasm-kernel

Здесь собрано всё, что в `tasks.md` помечено «не проверено» и требует редактора или платы. Тесты на ПК
по этим задачам уже проходят. Отметьте `[x]` у пройденной проверки, а если что-то не так, допишите строку
«Итог: …» и перенесите находку в `tasks.md`.

## Подготовка

- Плата: ESP32-C3 на COM5 с Rust-мастером. Пины C3: только GPIO 0–11 и 18–21, примеры рассчитаны на DevKit.
- Ручные команды мастеру (PowerShell):
  `cd D:\CrabLogic\firmware\master-rs; .\tools\master.ps1 COM5 list then info`.
  В `list` есть `mode=aot|interp`, `safe=`; в `info` есть `crabmod=свободно/всего` и области.
- Тестовый проект: копия `examples/blink` вне репозитория (чтобы не трогать пример). В `project.toml`
  поставьте `fqbn = "esp32:esp32:esp32c3"`, в `logic.toml` — пин 2.
- Сборка и запуск редактора: `cargo build -p crab-editor --bin crablogic-editor`, затем
  `target\debug\crablogic-editor.exe <папка проекта>`.
- Запишите, что лежит на плате до начала (`list`), чтобы потом вернуть как было.

## 1. Окно «Не все листы будут ускорены» (3.9)

Нет AOT-образа — значит, нет и ускорения. Вызываем это нарочно, подставив вместо wamrc чужую программу.

- [ ] 1.1 В настройках редактора поле «Путь к wamrc» → `C:\Windows\System32\where.exe`. Слегка поменяйте
  схему (например, период таймера), чтобы образ не взялся из кэша. Скорость листа — «Обычная».
- [ ] 1.2 Залейте модули на плату. **Ожидается:** окно «Не все листы будут ускорены» с листом, причиной
  «ускоренная сборка недоступна» и оценкой шага до/после; кнопки «Залить так» / «Отмена»; флажок
  «Больше не спрашивать для этих листов (скорость «Фоновая»)».
- [ ] 1.3 «Отмена». **Ожидается:** заливки нет, `list` не изменился, в журнале — отмена.
- [ ] 1.4 Снова залить → флажок → «Залить так». **Ожидается:** в свойствах листа скорость стала «Фоновая»;
  в `list` у модуля `mode=interp`; в окне состояния платы в колонке «Режим» — «без ускорения».
- [ ] 1.5 Повторная заливка того же листа окно больше не показывает.
- [ ] 1.6 В папке `.crab/<проект>/` появился `board.toml`, в нём `free`/`capacity` совпадают с `info`.

## 2. «Плата: не всё ускорено» в строке состояния (3.9)

- [ ] 2.1 Скорость листа обратно «Обычная», путь к wamrc очистить. Залить модули — окна нет, `mode=aot`,
  «Режим» — «ускорен». Строка состояния без предупреждения.
- [ ] 2.2 Закройте редактор или не трогайте его; в `board.toml` поставьте `free = 0`. **Ожидается:** не позже
  чем через ~1–2 с в строке состояния жёлтое «Плата: не всё ускорено»; при наведении — строка «Лист 1 (…)
  не поместится ускоренным: шаг ≈ … мкс вместо ≈ … мкс» и строка с датой последней заливки.
- [ ] 2.3 Кнопка «Проверка» — те же строки в журнале как предупреждения.
- [ ] 2.4 Правка схемы (добавить блок) — предупреждение пересчитывается примерно через 1 с, не мигает.
- [ ] 2.5 Новая заливка модулей перезаписывает `board.toml` — предупреждение пропадает.
- [ ] 2.6 Скорость «Быстрая» при `free = 0` — в журнале понятная ошибка (места для ускоренного нет).

## 3. Окно «Листы остановятся на время заливки» (3.2в-2)

- [ ] 3.1 Нужен лист, который заменяется «на месте» (новая версия не влезает рядом со старой). Проще всего
  Правка `board.toml` тут не поможет: расчёт замены перед заливкой читает живой `info`, поэтому нужен почти
  полный `crabmod` на самой плате. Если такого набора листов нет — «не проверено» до появления больших листов.
- [ ] 3.2 **Ожидается:** окно с оценкой времени остановки, «Залить» / «Отмена»; «Отмена» — ничего не меняется;
  «Залить» — перед `put` идёт `del`, лист после заливки работает.

## 4. Замена при нехватке памяти на плате (3.2в-3)

- [ ] 4.1 Заливка при полном `crabmod` — расчёт замены совпадает с тем, что сделал мастер (`info` до/после).
- [ ] 4.2 Лист, которому не хватает кучи рядом со старым: мастер выгружает старый экземпляр, грузит новый,
  выходы не дёргаются (аренды сохранены). При неудаче — возвращается старый. Можно отложить, как 3.1.

## 5. Статусы мастера в редакторе (3.2в-5, 3.2в-6)

- [ ] 5.1 Подключение к плате с Rust-мастером: редактор считает мастер актуальным, не просит перезалить
  мастер-прошивку.
- [ ] 5.2 Безопасный режим: если удастся вызвать три сброса подряд (сторожевой таймер/паника), после
  перезагрузки в `list` есть `safe=3`, сохранённые модули не запущены, в редакторе предупреждение
  «Мастер в безопасном режиме…»; `put` работает. Обычный сброс кнопкой снимает режим. Если вызвать нечем —
  «не проверено».

## 6. Заливка и AOT из окна редактора (3.3, 3.4, 3.10)

- [ ] 6.1 Заливка листа кнопкой из редактора (не из CLI): `mode=aot`, AOT-образ лёг в `.crab/<проект>/aot/`.
- [ ] 6.2 Окно состояния платы: колонка «Режим» показывает «ускорен» / «без ускорения» для двух листов
  разных скоростей.
- [ ] 6.3 Светодиод на пине гаснет при ошибке модуля (`modules/fault.wat`, `on_fault` 0) — глазами.

## После проверки

- Путь к wamrc в настройках — обратно пустой (или как было).
- Лишние модули с платы — `del <имя>`; на плате остаётся то, что было до начала.
- Отметить пункты в `tasks.md`: 3.9 «диалог вручную», 3.2в-2/3/5/6, 3.3, 3.4 — по итогам этого файла.
