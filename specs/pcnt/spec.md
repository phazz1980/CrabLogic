# Быстрый счётчик, частота и энкодер (PCNT)

## Цель

Считать импульсы быстрее шага схемы: расходомеры, счётчики продукции, датчики скорости, квадратурные
энкодеры (ручка, положение вала). Сейчас вход читается раз в шаг: при цикле 10 мс — не больше ~50 Гц,
импульсы между шагами теряются. Для ПЛК это типовой блок «быстрый счётчик» (HSC).

## Сценарии

1. Расходомер на GPIO: блок «Быстрый счётчик» считает импульсы до десятков кГц; выход — накопленное
   число, вход сброса обнуляет его.
2. Датчик оборотов: блок «Частота» выдаёт частоту в Гц (и обороты в минуту через масштабирование).
3. Энкодер A/B: блок «Энкодер» выдаёт позицию со знаком (x1/x2/x4), направление; сброс позиции.
4. Значение переживает перезагрузку, если пользователь сам сохраняет его блоком «Сохранение во флеш» —
   сам счётчик после сброса платы начинает с нуля (как у ПЛК без батарейки).

## Ограничения железа

- PCNT есть только у классического ESP32: 8 блоков, у каждого 2 канала, 16-битный аппаратный счёт
  (мастер расширяет до 32 бит), входной фильтр помех.
- У ESP32-C3 PCNT нет.

## Критерии готовности

1. ESP32: счётчик не теряет импульсы до 40 кГц (проверка: ШИМ платы → вход той же платы, сверка за 10 с);
   частота 1 Гц…40 кГц с погрешностью ≤ 1 % (окно задаётся); энкодер x4 не теряет шаги на скорости
   ≥ 10 кГц по фронтам.
2. Шаг схемы не ждёт счётчик: чтение — одно слово, без блокировок и прерываний в пути шага.
3. Переполнение 32 бит — заворачивается предсказуемо (документировано), не роняет схему.
4. Проверка схемы: на C3 — предупреждение «программный счёт, до N кГц»; больше 8 блоков — ошибка; вывод занят — ошибка.
5. Симуляция: вход счётчика из окна симуляции (число импульсов/частота задаётся вручную).
6. На каждый блок — тест сборки модуля, пример в `examples/`, `docs.md`, справка, новости.

## Вне задачи

Аппаратное сравнение со значением и выход по совпадению (позже), предустановка значения,
измерение длительности импульса (уже есть RMT для DHT22 — отдельная задача).

## Вопросы

Ответы пользователя 14.11.2026:
1. Три отдельных блока: «Быстрый счётчик», «Частота», «Энкодер».
2. На ESP32-C3 — запасной счёт на прерываниях GPIO (ниже предел частоты, нагрузка на процессор), проверка
   схемы выдаёт предупреждение с пределом частоты.
3. Счётчик считает вверх и вниз (вход направления), плюс сброс.

Ответы 14.11.2026 (план):
4. Частота: счёт за окно на высоких частотах, на низких (ниже ~1 кГц) — период по меткам времени фронтов
   (прерывание GPIO включается только там): ≤ 1 % от 1 Гц.
5. Проверка на железе (провода ШИМ → вход) — позже; сначала всё на ПК, мастер — сборка и проверка без проводов.
