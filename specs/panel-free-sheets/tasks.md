# Задачи: свободные листы щита

Исполнитель в скобках: **H** — Haiku по заданию, **Я** — основная сессия; после каждой задачи H —
ревью и тесты Sonnet. Параллельно только задачи без общих файлов.

## Этап 1. Части устройства (катушка)
- [x] **1. Ключи частей в раскладке** (H). `panel_layout.rs`: `part_key(id, part)`, разбор `"K1/coil"`,
  `rename`/`rename_all`/`prune` сохраняют суффикс. Проверка: юнит-тесты, `cargo test -p crab-core`.
- [x] **2. Катушка — самостоятельный символ** (H). `crab-schematic`: катушка размещённого `K1/coil`
  рисуется символом катушки (A1/A2) в указанном месте, а не коробкой `draw_manual`; провода к A1/A2
  идут к ней. Проверка: тест листа (символ, порты A1/A2, провода).
- [x] **3. Таблица контактов под катушкой и ссылки** (H, ревью Я). Под катушкой — контакты аппарата
  с `/лист.столбец` по фактическому положению; у контакта — ссылка на катушку. Проверка: тест
  «сдвинул контакт — ссылка под катушкой изменилась».
  Сделано 22.11.2026: ручная катушка регистрируется в `coil_at` (силовой и управляющий лист), таблица
  `1-N /лист.столбец` + строка на доп. контакт под каждой катушкой; при длинной таблице шины 24V/0V
  опускаются. PDF `pump` детерминирован (сверено). Не сделано: шина не ограничена низом листа при
  очень длинной таблице; глазами не проверено.

## Этап 2. Один вид листа
- [ ] **4. Модель листов** (H). `SheetMeta { caption }`, `PanelLayout.sheets`; `Placed.power` читается,
  не пишется; круг «запись → чтение», старый файл без `sheets`. Проверка: тесты `crab-core`.
- [ ] **5. Сборка листов в один ряд** (Я — интерфейс, H — код). `lib.rs`: общая нумерация, подпись листа
  из `sheets` (по умолчанию «Силовая часть» / «Цепи управления» по содержимому генератора),
  размещённое рисуется общим путём на любом листе. Проверка: тесты `power_sheet`, `control_sheet`,
  `layout`; PDF `examples/pump` по составу тот же.
- [ ] **6. Перенос старых проектов** (H). `crab_schematic::migrate_layout`; вызов в редакторе, CLI и
  MCP. Проверка: тест на старом `panel_layout.toml` с `power = false`.
- [ ] **7. Плата и шины как размещаемые элементы** (H). Ключи `board`, `bus/24V`, `bus/0V`.
  Проверка: тест «шина на другом листе, ссылка `/лист.столбец`».
