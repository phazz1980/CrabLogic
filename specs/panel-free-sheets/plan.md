# План: свободные листы щита

Этапы идут по одному, каждый оставляет щит рабочим (тесты зелёные, PDF собирается).
Принцип из спеки: соединения — в модели (`panel.toml`), положение — в раскладке (`panel_layout.toml`).

## Архитектурные решения
1. **Часть устройства, а не новое устройство.** Катушка — часть контактора или реле, отдельного
   `DeviceKind::Coil` не будет (задача 6 `panel-coil` отменяется). Обозначение одно (`K1`), привязка
   к выходу (`bind`) остаётся у аппарата. Доп. контакты остаются отдельными устройствами `Aux` (у них
   свои `form`, `pins`, `series`). Ключ части в раскладке: `"<id>/<часть>"` (`K1/coil`); `/` в
   обозначениях запрещён (`is_valid_designation`), поэтому ключ однозначен. Без части — главный
   символ (`K1`). `PanelLayout::rename` сохраняет суффикс части.
2. **Один вид листа.** `PanelLayout.sheets: Vec<SheetMeta { caption }>` — подписи листов по порядку.
   Номер листа в `Placed.sheet` и `bus_to` — общий, от первого листа схемы (без титульного и таблиц).
   Листов в документе: `max(нужно генератору, sheets.len(), последний занятый + 1)`.
3. **Генератор остаётся живым** для неразмещённых устройств (ответ 1): силовые цепочки — на первых
   листах, колонки катушек и контактов — на следующих, как сейчас. Перетащенная мышью часть
   становится размещённой и рисуется общим путём. «Разложить заново всё» = убрать `placed` и сдвиги.
4. **Перенос старых проектов** нельзя сделать в `crab-core` при загрузке: номер первого листа
   управления знает только генератор. Поэтому `crab_schematic::migrate_layout(&mut Project)`:
   `Placed{power:false, sheet:i}` → общий номер `число силовых + i`, поле `power` читается и больше
   не пишется. Вызов — сразу после загрузки в редакторе, CLI (`panel`) и MCP (`folder.rs`).
5. **Плата и шины 24V/0V** — размещаемые элементы с ключами `board`, `bus/24V`, `bus/0V`; без
   размещения стоят там, где их ставит генератор.
6. Удалить лист можно, только если генератор на нём ничего не рисует; размещённое на нём уходит
   обратно в дерево (`[✕]`).

## Затронутые места
- `crab-core/src/panel_layout.rs` — `sheets`, `SheetMeta`, ключи частей, `rename`/`prune` с частями,
  `Placed.power` только для чтения.
- `crab-schematic`: `lib.rs` (сборка листов в один ряд, `migrate_layout`), `power.rs` и
  `control.rs` (общий путь рисования размещённого, подпись из `sheets`), `symbols.rs` (катушка как
  самостоятельный символ, таблица контактов), `xref.rs` (ссылки часть ↔ часть по положению).
- `crab-editor/src/panelview.rs` — убрать `is_control`/`is_power`, бросок любой части на любой лист,
  меню листа (добавить, удалить, подпись), «Разложить заново всё»; `app/project.rs` — вызов переноса.
- `crab-ai/src/folder.rs`, `crab-cli` — вызов переноса.
- Справка `help/18-panel.md`, новости, `examples/pump`.

## Риски
- `panelview.rs` (~2800 строк) — интерактив делаю сам, не субагентами.
- Перенос: проверить побайтно, что старый `examples/pump` после переноса даёт тот же PDF (кроме
  заголовков листов).
