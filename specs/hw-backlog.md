# Аппаратные возможности ESP32: что ещё не сделано (14.11.2026)

В работе (спеки, ждут ответов на вопросы): `specs/safety-audit` (сторож шага, безопасное состояние),
`specs/pcnt` (быстрый счётчик, частота, энкодер), `specs/dac` (аналоговый выход).

Очередь после них — пользователь попросил взять в план весь список. Предлагаемый порядок (польза для
автоматики → объём работы); на каждую — своя спека перед кодом.

| # | Что | Чипы | Зачем | Объём |
|---|---|---|---|---|
| 1 | OTA мастера по сети | ESP32, C3 | обновить прошивку без USB на объекте; модули уже по сети не льются — сделать вместе | большой: второй раздел приложения (флеш 4 МБ: app 2 МБ сейчас — нужна новая таблица разделов), откат при сбое загрузки |
| 2 | Датчик температуры кристалла | C3 (у ESP32 нет) | диагностика перегрева шкафа | малый: блок + функция мастера |
| 3 | Сенсорные входы (touch) | ESP32 (у C3 нет) | кнопки без механики | малый–средний: блок, порог, фильтр |
| 4 | ESP-NOW | ESP32, C3 | связь плат без роутера; хорошо ложится на шину `pubsub-bus` между платами | средний |
| 5 | Карта SD | ESP32, C3 (SPI) | архив трендов/журнал | средний: драйвер файловой системы, запись в фоне, износ |
| 6 | MCPWM | ESP32 (у C3 нет) | ШИМ с мёртвым временем, мосты, двигатели | средний |
| 7 | BLE | ESP32, C3 | настройка с телефона, беспроводные датчики | большой: память (~50–70 КБ кучи), конфликт с Wi-Fi по памяти на C3 |
| 8 | Глубокий сон | ESP32, C3 | автономные датчики на батарее; для ПЛК редко | средний: противоречит непрерывному скану — отдельный режим проекта |
| 9 | I²S | ESP32, C3 | звук, цифровые микрофоны; для автоматики почти не нужен | средний; последним |

Риски общие: флеш (app занят на 77–80 %), куча C3 с Wi-Fi, каждый новый драйвер — в фоне, не в пути шага
(`specs/safety-audit`).
