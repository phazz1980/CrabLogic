1. [x] **Геометрия страницы.** Поля 5 мм, 8 столбцов (A4) / 12 (A3), зоны только по столбцам,
   `zone`/`zone_rect`, рамка. Проверка: тесты `doc.rs` (границы, столбец точки, прямоугольник
   столбца), осмотр PDF.
2. [x] **Ссылки.** `Xref` с зоной-столбцом, `find_ref`, подписи; обновить тесты со `C3`.
   Проверка: тесты `xref.rs`, `control_sheet.rs`, `power_sheet.rs`.
3. [x] **Редактор.** Подсветка столбца, переход по клику, тесты `panelview.rs`.
4. [x] **Справка.** `help/18-panel.md`, `help/09-news.md`.
5. [x] **Сверка.** Критерии спеки, `cargo fmt`, `clippy`, `test`, пример `examples/pump` собирается,
   что не проверено глазами.
6. [x] **Размеры символов.** Контакты автомата, УЗО, контактора и реле высотой ~35 u с номерами
   клемм у каждого полюса, обозначение слева, ссылка под ним; шаг рядов (`HEIGHT`, `MIN_PITCH`,
   `MAX_PITCH`) и размеры двигателя, нагрузки, блока питания пропорционально. Проверка:
   тесты символов и листов, пример `examples/pump`, осмотр PDF.
