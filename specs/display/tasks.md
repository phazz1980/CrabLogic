# Дисплеи и меню — задачи

Код пишут агенты по заданиям, основная сессия проверяет diff и работает с платой.

1. [ ] Ядро: описания `oled`, `lcd`, `menu`, `disp_*`, `menu_item` в `library/`; теги виджетов экранов, переименование
   и удаление через общий механизм веб-виджетов; проверки из плана. Проверка: тесты `crab-core` (теги, ошибки).
2. [ ] `crab.config` в `user_block.rs`: данные в модуле листа, шим, лимиты; проверка в `block check`. Проверка: тест
   `crab-codegen` с WAT-драйвером, читающим конфиг; `help/12-drivers.md`, `Архитектура и план.md`.
3. [ ] Формат конфига дисплея (экраны, виджеты, меню) — общий крейт `crates/crab-ui-format` (`no_std`, сериализация
   на ПК, разбор в драйвере). Проверка: круговой тест на ПК.
4. [ ] Генератор: экземпляр дисплея получает конфиг, входы виджетов и меню, выходы меню пишут переменные; порты блока
   `menu` присоединяются к дисплею. Проверка: снимок модуля, тест маршрутизации в `crab-sim`.
5. [ ] Драйвер `drivers/display`: шрифты 8 и 16 (кириллица), OLED SSD1306/SH1106, LCD HD44780+PCF8574 с CGRAM,
   виджеты, кадр частями, движок меню с тайм-аутом. Проверка: тесты отрисовки на ПК (кадр → картинка), `block check`.
6. [ ] Симуляция: модель SSD1306/SH1106/HD44780 на заглушке шины в `crab-sim`, окно «Дисплей» в редакторе.
   Проверка: тест симуляции (кадр совпадает с эталоном), глазами в редакторе.
7. [ ] Конструктор: дисплеи в списке страниц, сетка экрана, виджеты `disp_*`, вкладка «Меню», предпросмотр тем же
   шрифтом. Проверка: правка `web.toml` в конструкторе → теги в редакторе; глазами в браузере.
8. [ ] Пример `examples/display_menu` (OLED + LCD + меню уставок с `retain`), справка (новая страница «Дисплеи и
   меню», `02-editor.md`, `09-news.md`), `docs.md` блоков, переводы. Проверка: `check`, `gen-wasm`, `audit-rust`.
9. [ ] Плата: ESP32 COM10 + SSD1306 пользователя — экраны, меню кнопками, уставка после перезагрузки, время шага;
   LCD и SH1106 — если будут подключены. Проверка: замер `list` (us=), фото/описание результата.
10. [ ] Сверка с критериями `spec.md`; что не проверено на железе — в ответе.
