# Задачи: блоки на коде

Порядок сверху вниз; у каждой — как проверить.

## 1. Ядро и сборка C++

- [ ] 1.1 `crab-core::codeblock`: разбор `CRAB_INPUT/PARAM/OUTPUT/PIN/I2C_ADDRESS` из `block.cpp` → порты
  `BlockDef`, ошибки со строками. — Юнит-тесты: порядок, типы, значения по умолчанию, ошибки (не литерал,
  повтор имени, внутри функции).
- [ ] 1.2 `crab.h` (вшит в `crab-codegen`): время, GPIO, `Wire`, `Serial1/2`, `SPI`, `OneWire`, `Serial.print`,
  `String`, математика; запрещённые функции дают ошибку с подсказкой. — Сборка набора фрагментов zig'ом (тест с
  `CRAB_ZIG`), фрагмент с `delay()` даёт русскую подсказку.
- [ ] 1.3 `crab-codegen::codeblock::wrap`: обёртка с `init/step`, `millis` из `dt`, `#line` на строки `block.cpp`.
  — Снимок обёртки для примера.
- [ ] 1.4 `crab-build::wasm::compile_block`: флаги драйверов, проверка модуля, разбор ошибок clang в строки
  `block.cpp`, перевод частых. — Тесты: модуль проходит `driver.rs`; ошибка на строке 7 сообщается строкой 7.
- [ ] 1.5 Пример `examples/code_block/` (блок «Тревога с задержкой» на C++): `crab-sim` даёт ожидаемые выходы
  на сценарии входов; модуль листа собирается `gen-wasm`. — Тест в `crab-sim/tests` (с `CRAB_ZIG`).
- [ ] 1.6 CLI: `crablogic block build <папка>` (порты → `block.toml`, сборка `block.wasm`). — Ручной прогон на примере.
