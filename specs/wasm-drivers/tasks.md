# Драйверы железа в WASM — задачи

- [x] 1. `crab-codegen/src/wasm/driver.rs`: разбор и вклейка `block.wasm` (сдвиг индексов, окно памяти, отказ на
      недопустимое). Проверка: модульные тесты на `wat` (сдвиг `offset`, данные, глобали, ошибки).
- [x] 2. Генератор: блок с `block.wasm` в модуле — ячейки `f64`, прокладки `crab.*`/`bus.*` → `crab.bus`, вызов
      `step`/`init`, заявки ресурсов в `init`, `needs`/`allow` = `bus`. Проверка: тест в `crab-sim` (модуль
      запускается в wasmi с заглушкой `bus`, выходы драйвера доходят до схемы).
- [x] 3. `crab-kernel`: импорт `crab.bus` в `abi.rs`; заглушка хоста на ПК. Проверка: тест `check_imports`.
- [x] 4. Мастер: `bus_cfg.rs` (заявки, проверка, тесты на ПК), `board/bus.rs` (GPIO, I²C, UART, micros, delay_us,
      log), возможность `bus`. Проверка: сборка C3 и ESP32, `cargo test` мастера.
- [x] 5. Ядро/симуляция: `PortDef.sim`, драйвер в `crab-sim::schema` даёт `sim`; пробный прогон — сообщение.
      Проверка: тесты `crab-core`, `crab-sim`.
- [x] 6. Пример `examples/wasm_driver/` (I²C-датчик BMP280 на Rust и C, `build.ps1`), справка: страница драйверов,
      `10-block-editor.md`, `05-build.md`, новости. Проверка: `gen-wasm` примера.
- [x] 7. SPI, затем 1-Wire (`bus.spi_*`, `bus.onewire_*`) — тем же путём.
- [x] 8. Сверка с критериями; на железе — не проверено.

Итог v1 (11.11.2026): пункты 1–6 сделаны, проверки — тесты `crab-codegen` (driver), `crab-sim` (`driver_module`,
`driver_sim`, `driver_example`: BMP280 на Rust и на C даёт 25,08 °C и 1006,53 гПа на данных даташита),
`bus_cfg` мастера на ПК, сборка мастера C3 и ESP32. По ходу добавлено: `memory.copy/fill` через помощники
(готовая `core` у Rust их содержит), окно не больше 32 КБ и обязательный `__heap_base`, постоянные параметры
видны в `init` (сегмент данных). На железе — не проверено.

SPI и 1-Wire (11.11.2026): `bus.spi_*` (ops 50–51; SPI3 на ESP32, SPI2 на C3), `bus.ow_*` (ops 60–64, программный
1-Wire с выключенными прерываниями на время бита). Проверка: тест `driver_module` (вызовы и указатели), `bus_cfg`
мастера, сборка C3 и ESP32. На железе не проверено.
