# План: блок «Перезапуск платы»

## Как

Перезапуск — действие мастера, модуль WASM только просит его. Новый импорт ABI `restart(delay_ms) -> i32`
с правом `Allow` (нужен `allow = ["restart"]` в манифесте), id 33 в конце таблицы; версия ABI остаётся 5 (как у `dac_write`),
возможность `restart` добавлена в `modcaps=` мастера и в `MASTER_CAPS`: старый мастер модуль не примет и объяснит почему.
Операции: 0 запрос с задержкой, 1 отмена, 2 текст причины сброса в память модуля. Блок фронта, задержки и защиты
считается в самом блоке (память `memory = true`, `single = true`); импорт вызывается один раз, когда
задержка вышла.

## Затронутые места

- `crates/crab-kernel/src/abi.rs` — импорт `restart` (`id::RESTART`, `restart_op`); версия ABI та же; тест списка импортов.
- `crates/crab-kernel` (хост ПК, симуляция) — заглушка `StubIo`: запоминает запрос (`restart_request`).
- `firmware/master-rs/src/board/` — обработка импорта: ставит флаг `restart_at`; в конце шага мастер
  останавливает модули (выходы в безопасное состояние), ждёт сохранения retain и вызывает `esp_restart`.
  Причина сброса `ESP_RST_SW` в `count_boot` уже относится к `Reset::Other` — счётчик плохих загрузок
  не растёт. Проверить, что `Other` сбрасывает счётчик (иначе петля перезапусков не уведёт в safe mode —
  и это нормально, её закрывает `guard`).
- `library/restart/block.toml` + `docs.md` — вход `go`, выходы `pending`, `blocked`, (`reason`),
  параметры `delay`, `guard`.
- `crates/crab-codegen` — генерация блока, тест `library_modules.rs`.
- `crates/crab-core` — проверка: один блок на проект (`single`); предупреждение, если `go` не подключён.
- `examples/restart-on-offline/` — самолечение по потере MQTT/Wi-Fi.
- `help/` (блоки сети/система), `help/09-news.md`, переводы после.

## Риски

- Совместимость: ABI не менялся, старые модули грузятся как раньше.
- Петля перезапусков при ошибке в схеме: закрыта `guard`; дополнительно — журнал событий пишет
  «перезапуск по команде схемы» перед `esp_restart`.
- Потеря несохранённых `retain`: перезапуск ждёт очередь записи (`retain::is_flushed`), но не дольше 500 мс.
