# Защита флеша от износа — план

## Данные проекта (`crab-core`)

- `project.toml`: новая необязательная секция `[retain]` — `settle_s` (покой, по умолчанию 5), `period_s`
  (не чаще, по умолчанию 600). Без секции — умолчания; при сохранении умолчания не пишутся.
- `Var` (`vars.rs`): необязательные `settle_s`, `period_s` — переопределение для переменной.
  Функция `Project::retain_timing(&Var) -> (settle_ms, period_ms)`.
- `block.toml`: у выхода необязательный флаг `fast = true` («меняется часто»). Ставим у `analog_in.out`,
  `counter` (счёт), `generator`, прошедшего времени `timer_on`/`timer_off` (если есть), `ds18b20`, `dht22`
  и прочих аналоговых/измерительных выходов библиотеки.
- Проверка (`check`): предупреждение `retain_fast`, если `retain`-переменная получает значение напрямую
  с выхода `fast` (через `var_set`/тег — как проверка находит источник переменной), с советом.

## Модуль листа (`crab-codegen/src/wasm/retain.rs`)

На каждую сохраняемую переменную вместо `last` три глобала: `prev` (значение прошлого шага), `changed_at`
(когда значение последний раз изменилось), `written_at` (когда записали; при старте = now − period).
Каждый шаг: если значение ≠ `prev` → `prev = value, changed_at = now`. Если value ≠ `saved`
и `now − changed_at ≥ settle` и `now − written_at ≥ period` → `retain(1, key, value)`, `saved = value`,
`written_at = now`. Для текстов то же, сравнение — как сейчас (`text_call(5…)`), `prev` — копия буфера
или CRC текста. Числа берутся из `retain_timing`. ABI мастера не меняется.

Для меню дисплея (задача `specs/display`): подтверждение «ОК» сохраняет параметр сразу, минуя покой и период
(генератор сбрасывает `changed_at`/`written_at` этой переменной). Это делается в задаче 4 дисплеев.

## Симуляция (`crab-sim`)

Счётчик записей `retain`/`retain_text` в `mcu.rs` — для тестов сценариев 1–2.

## Мастер (`firmware/master-rs/src/board/retain.rs`, `mod.rs`)

Счётчик фактических `nvs_set_*` (с включения) и кольцо по минутам за последний час; `info` печатает
строку `nvs writes=<всего> hour=<за час> free=<свободных записей> used=<занято>` (`nvs_get_stats`).
`nvs_commit` остаётся после каждой записи (износа не добавляет). Тест разбора на ПК, если строка разбирается.

## Редактор (`crab-editor`)

- Настройки проекта: два поля «Сохранение во флеш: покой, с» и «не чаще, с».
- Свойства переменной (`dialogs/mod.rs`): те же два поля, видны при `retain`, пусто — как в проекте.
- Отладка: строка `nvs` из `info` в панели/состоянии; > 60 в час — предупреждение.
- i18n: новые строки во все `i18n/*.json`.

## Риски

- Уставка, изменённая меньше чем за `settle` до пропадания питания, теряется — описать в справке.
- Размер модуля: +2 глобала на переменную, код на переменную чуть больше — снимки обновятся.
