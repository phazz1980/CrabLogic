# Задачи: редактор символов

1. [ ] **Крейт `crab-symbols`: модель и SVG.** `SymbolSet`, `Image`, `Shape`, `Port`; разбор
   подмножества SVG (`line polyline polygon rect circle path text g`) и запись; `set.toml`.
   Проверка: тесты на круг чтение/запись, на отброшенные элементы с предупреждением, на
   дуги `A`.
2. [ ] **Растягивание.** Полюса 1–4, форма NO/NC, число клемм: `expand(image, params)` →
   список фигур и портов. Проверка: тесты на 1–4 полюса и обе формы.
3. [ ] **Отрисовка.** Преобразование в `Canvas`-операции; `crab-schematic` рисует набор
   вместо встроенного символа, если он назначен; порты — в сцену. Проверка: golden-тест
   «встроенный контактор → SVG → отрисовка» равен встроенному.
4. [ ] **Библиотека.** Каталог `library/symbols/`, загрузка и ошибки, выбор набора для вида в
   `panel.toml`, примеры наборов (контактор, автомат, клемма, доп. контакт). Проверка: тесты
   `crab-core`, пример в `examples/`.
5. [ ] **«Копировать как…».** Встроенный символ → SVG-набор. Проверка: тест равенства
   рисунка, ручная проверка в Inkscape.
6. [ ] **Окно редактора.** Холст, сетка, фигуры, порты, свойства, предпросмотр 1–4 полюсов,
   отмена/повтор, сохранение. Проверка: тесты логики в `crab-editor`, осмотр руками.
7. [ ] **Экспорт/импорт, переименование, удаление своих.** Проверка: тесты и осмотр.
8. [ ] **Проверка набора.** Порты не повторяются, у вида есть нужные порты, символ
   помещается в колонку. Проверка: тесты `crab-symbols`.
9. [ ] **ИИ.** `list_symbol_sets`, `read_symbol_set`, `write_symbol_set`. Проверка: тесты
   `crab-ai`.
10. [ ] **Справка и новости.** Новая страница `help/`, `help/09-news.md`. Проверка: чтение.
11. [ ] **Сверка.** Критерии спеки, `cargo fmt`, `clippy`, `test`; что не проверено глазами.
