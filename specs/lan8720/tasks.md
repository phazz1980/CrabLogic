# Ethernet на LAN8720 — задачи

- [x] 1. `block.toml`: `chip`, `preset`, свои параметры, скрытые `fixed`-выводы с `when`; SPI-параметры только
      для W5500. Проверка: библиотека грузится (`crab-core` тесты), старый пример W5500 проходит `check` без изменений.
- [x] 2. `crab_core::lan8720::Lan8720` (в ядре) + тест: для каждого пресета выводы совпадают с активными `fixed`-выводами.
- [x] 3. `check`: ошибка «нет EMAC» не на ESP32, предупреждение «такт на GPIO0 без питания PHY», пересечение
      выводов RMII с другим блоком. Проверка: тесты в `crab-core`/`crab-blocks`.
- [x] 4. C++: ветка LAN8720 в `net::ethernet`. Проверка: снимок, `arduino-cli compile` примера.
- [x] 5. WASM: коды чипа и RMII в op 6. Проверка: тест генерации (байты вызовов), W5500 без изменений.
- [x] 6. Мастер: `eth_cfg.rs` (разбор кодов, проверка выводов, тесты на ПК), `eth.rs` — RMII через EMAC на ESP32,
      журнал на C3. Проверка: сборка C3 и ESP32 (`cargo +esp`), `cargo test` мастера на ПК.
- [x] 7. Пример `examples/eth_lan8720/`, справка (`library/ethernet/docs.md`, `help/`), новости.
- [x] 8. Сверка с критериями спеки; на железе — не проверено (нет платы).
