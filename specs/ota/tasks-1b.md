Нужно: кнопка «Найти платы» рядом с вводом адреса и команда `crablogic find`, которые показывают платы CrabLogic в локальной сети (имя или id платы, IP, чип, версия мастера, короткий хеш проекта, есть ли ключ для сети) и подставляют выбранную в `[board] host`. Как: редактор шлёт UDP-запрос широковещательно (порт фиксированный, отдельный от порта команд), платы с включённым потоком `crab-netcmd` отвечают одиночным пакетом; плата ничего не рассылает сама (нет постоянного шума и нагрузки). Ответ не содержит секретов (пароль и ключ по-прежнему нужны для входа), список не включает платы без записанного ключа или помечает их. Ограничения сказать в справке: широковещание не проходит через другую подсеть и VLAN, а брандмауэр Windows может блокировать ответы (тогда адрес вводят руками). Позже, по желанию, mDNS-имя `crablogic-<id>.local` (если не вырастет мастер).
