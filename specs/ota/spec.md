# Обновление по сети: мастер (OTA) и модули

## Цель

Обновлять плату на объекте без USB: модули (листы WASM) и, если хватает флеша, саму мастер-прошивку — из
редактора и `crablogic` по Wi-Fi или Ethernet. Промышленная надёжность: обрыв связи или питания во время
обновления не оставляет плату без рабочей прошивки, новая прошивка, которая не поднялась, откатывается сама.

## Факты (14.11.2026)

- Флеш 4 МБ: `factory` 2 МБ (мастер ESP32 ~1,63 МБ, C3 ~1,37 МБ), `crabmod` 1,875 МБ (модули, AOT — с флеша),
  `coredump` 64 КБ, NVS 24 КБ.
- OTA требует два слота приложения + `otadata`. Два слота по 1,75 МБ на 4 МБ оставляют модулям ~350 КБ (сейчас
  1,875 МБ; типичный лист AOT — 3–15 КБ, лист на 500 блоков — до ~80 КБ).
- 11.11.2026 решено: OTA нет (места нет), по сети — только модули (`specs/net-upload` в файле архитектуры).
  Эта спека пересматривает решение по просьбе пользователя (очередь `specs/hw-backlog.md`, п. 1).
- Пароль отладки (`specs/debug-auth`) сделан для старой отладочной прошивки; в Rust-мастере входа по паролю нет.

## Сценарии

1. Модули по сети: в редакторе «Залить» по адресу платы вместо COM-порта — те же модули, горячая замена, как по USB.
2. Мастер по сети (если принят вариант с OTA): «Залить мастер» по адресу; плата качает образ во второй слот,
   проверяет, перезагружается в него; если новый мастер не подтвердил себя (старт, схема шагает) за N секунд —
   возврат на прежний.
3. Без пароля или с неверным паролем плата по сети ничего не принимает.
4. `crablogic gen-wasm --upload --host <адрес>` и `crablogic flash-master --host <адрес>` — то же из командной строки.

## Критерии готовности (черновик)

1. Модуль по сети заливается и подменяется без остановки остальных; обрыв на середине — работает прежний.
2. (OTA) Обрыв связи или питания на любом этапе — плата загружается в рабочий мастер; не подтвердивший себя
   мастер откатывается сам (проверка на плате: выдернуть питание посреди записи, залить заведомо падающий мастер).
3. Образ проверяется до переключения (CRC/SHA-256, чип, версия протокола).
4. Пароль обязателен для обновления по сети; пароль не идёт открытым текстом.
5. Шаг схемы не ждёт приёма образа (приём — фоновая задача, запись во флеш — без остановки шага дольше лимита).
6. Справка, новости, замер `crablogic bench`.

## Вне задачи (черновик)

Онлайн-отладка по сети (транспорт позже), загрузка с внешнего сервера по URL, подпись образов (secure boot),
шифрование канала (TLS).

## Решения (ответы пользователя 14.11.2026)

1. **Раскладка по объёму флеша.** Платы с 8/16 МБ — OTA мастера и модули по сети (два слота приложения, раздел
   модулей не меньше нынешнего). Платы с 4 МБ — раскладка как сейчас: модули по сети, мастер по USB. Решение
   11.11.2026 («OTA нет») остаётся в силе для 4 МБ.
2. **Транспорт:** ПК отдаёт образ плате — редактор и `crablogic` подключаются к плате по TCP (та же шина команд, что
   по USB); загрузка платой по URL — вне задачи.
3. **Защита:** пароль проекта (вызов-ответ, не открытым текстом) + проверка образа (CRC/SHA-256, чип, версия);
   подпись образов и TLS — позже.
4. **Откат:** новый мастер, не подтвердивший себя за 30 с (старт, схема шагает), откатывается сам; запись в журнал.

## Ограничение проверки

Обе тестовые платы (ESP32 COM10, C3 COM5) — 4 МБ флеша: OTA мастера на них не включается. Модули по сети
проверяются на обеих; OTA мастера — только на плате с 8/16 МБ (нет в наличии) или на 4 МБ с временной тестовой
раскладкой (маленький мастер без сети не соберётся — проверить отдельно, возможно ли).
