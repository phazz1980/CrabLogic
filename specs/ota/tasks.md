# Задачи: фаза 1 — модули по сети

1. [x] Мастер: ключ в NVS (`crab_net/key`), команда `netkey` только по USB, логика входа в `netauth.rs` (hex,
   ограничение попыток, сравнение без раннего выхода). Проверка: хост-тесты (`netauth`, разбор `netkey`).
2. [x] Мастер: `board/netcmd.rs` — сервер TCP 4040, вход вызов-ответ (HMAC-SHA256 из mbedtls), 5 неудач → 60 с,
   байты в общий разборщик (`io::feed`), USB не читается, пока вошёл клиент, копия ответов клиенту, очистка
   разборщика при входе/выходе, отключение молчащего 2 мин. Проверка на ESP32 и C3: верный пароль — `ok`, `info`/`list`
   за ~30 мс; неверный — `err auth`; `netkey` по сети — отказ; второй клиент — `err busy`; 6-я неверная попытка и
   верный пароль во время блокировки — закрыто; обрыв клиента замечается за 0,6–0,7 с.
3. [x] ПК: `crab-build/net_link.rs` — подключение с входом, `set_net_key`, `BoardLink`; тесты на поддельном мастере
   (вход, отказы, заливка модуля через TCP).
4. [x] `crab-cli`: `gen-wasm --upload --host`, `netkey`; `crab-ai` передаёт `--host` для адреса. Проверка на платах:
   заливка с горячей заменой по сети (ESP32 1,0 с, C3 0,4 с, замена 2 мс), обрыв посреди заливки — работает прежний
   модуль, вход снова доступен.
5. [x] Редактор: «По сети…» в выборе платы (`[board] host`), заливка по сети, запись ключа. Проверка: сборка и
   тесты workspace; вживую в окне редактора не проверено.
6. [x] Справка [x], новости [x], `docs.md` Wi-Fi/Ethernet [x]; замер `crablogic bench` ESP32 и C3; нагрузка: 19 запросов/с
   по сети — ESP32 0 опозданий, C3 13 из 1007 шагов > 50 мкс (пауза до 10,5 мс). Строки в `bench/history.md`.
7. [x] Поток `crab-netcmd` запускается только при записанном ключе (при старте или по `netkey`): без ключа плата
   не тратит ~7 КБ кучи. `info` показывает `thread=`. Проверка: ESP32 208,9 КБ без ключа / 201,5 КБ с ключом,
   `netkey` по USB запускает поток без перезагрузки, вход по сети после этого — `ok`.

Не сделано в фазе 1 (записать в следующие задачи): `upload-wasm`, `monitor`, `pull`, `report`, `bench` по сети;
онлайн-отладка по сети; OTA мастера (фаза 2, плата 8/16 МБ).
