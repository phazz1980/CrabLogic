# План: отчёт об ошибке

## Крейты и файлы

- `crab-editor`: пункт меню и окно отчёта (`src/report.rs`), хук паники (`std::panic::set_hook` пишет
  `panic.txt` в папку данных программы), кольцевой журнал на диске (`editor.log`, 2 файла по 512 КБ),
  вопрос при запуске, если остался `panic.txt`. ZIP пишет тот же крейт `zip`, что и `.crab`.
- `crab-core`: маскировка секретов при копии проекта — по типу поля (пароли и ключи в настройках сети, MQTT,
  Sparkplug, параметры блоков с признаком `secret` в `block.toml`). Функция `mask_secrets(&Project) -> Project`
  и тест «в TOML нет ни одного исходного значения».
- `crab-debug`: сбор данных платы — `list`, `info`, `log`, новая команда `core` (см. ниже); всё с тайм-аутами,
  ошибка любого шага не прерывает отчёт.
- Мастер (`firmware/master-rs`): включить дамп сбоя во флеш (`CONFIG_ESP_COREDUMP_ENABLE_TO_FLASH`, формат ELF,
  контрольная сумма CRC32) в `sdkconfig.defaults`; причина последнего перезапуска и `bad_boots` — в `info`;
  команды `core info` (есть ли дамп, длина, CRC), `core read <смещение>` (порция в hex с CRC, между шагами —
  чтение флеша не в шаге), `core erase`. Дамп пишет ESP-IDF при панике — рабочий цикл не затрагивается.
- `crab-cli`: `crablogic report [--port COMx] [--project путь] [--out файл]` — то же без окна; `crablogic report
  decode <zip>` — расшифровка дампа (`espcoredump` из ESP-IDF и ELF мастера той же версии).
- Выпуск: ELF мастера каждой версии сохраняется рядом с релизом (`dist/`, ассет релиза), иначе дамп не
  расшифровать. Отметить в `release-process`.

## Формат

ZIP: `report.md`, `editor.log`, `panic.txt?`, `board.txt?`, `coredump.elf?`, `project.crab?`. Имя:
`crablogic-report-<дата>-<время>.zip`, по умолчанию на рабочий стол.

## Риски

- Секреты в неожиданных местах (тексты констант, комментарии): маскируем известные поля, в окне — предупреждение
  «проверьте проект перед отправкой».
- Дамп на C3 при малой куче: проверить, что запись дампа помещается в 64 КБ (только задачи, не вся память).
- `espcoredump` нужен только разработчику; у тестера расшифровки нет.
