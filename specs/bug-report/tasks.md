# Задачи: отчёт об ошибке

1. [ ] `crab-core`: `mask_secrets` и признак `secret` у параметров блоков. Проверка: тест на проекте с Wi-Fi,
   MQTT, Modbus — в TOML нет исходных значений.
2. [ ] Мастер: дамп сбоя во флеш (sdkconfig), `core info/read/erase`, причина перезапуска в `info`. Проверка:
   хост-тесты разбора команд; на ESP32 и C3 — искусственная паника (`selftest panic`), дамп читается.
3. [ ] `crab-debug`: сбор `board.txt` и дампа порциями с CRC. Проверка: тест на поддельном порту.
4. [ ] Редактор: журнал на диске (кольцо 2×512 КБ), хук паники, окно «Сообщить об ошибке», вопрос при запуске.
   Проверка: тесты сборки ZIP, вручную в окне.
5. [ ] CLI: `crablogic report` и `report decode`. Проверка: тест сборки ZIP; расшифровка дампа с платы.
6. [ ] Выпуск: ELF мастера в ассеты релиза.
7. [ ] Справка: страница «Сообщить об ошибке», 09-news. Сверка с критериями спеки.
