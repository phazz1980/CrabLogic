# План: поиск плат в сети

- **Протокол** (`firmware/master-rs/src/netfind.rs`, чистый модуль без железа, как `netauth`): запрос
  `CRABFIND` + версия протокола; ответ — фиксированный двоичный или строчный пакет с полями выше, длина
  ограничена, разбор с проверкой длины и версии. Тесты на ПК. Тот же модуль подключает `crab-cli`/редактор
  (общий крейт или копия формата — решить при реализации по тому, как сейчас делится `netauth`).
- **Прошивка** (`board/netcmd.rs` или рядом, отдельная короткая задача `crab-netfind` или вызов из
  существующего потока сети): UDP-сокет на порту поиска, ответ юникастом отправителю; лимит частоты;
  имя проекта и id плат берутся из `info`, ключ — из флага `HAS_KEY`. Мастер придётся перезалить, замер bench.
- **`crab-debug` или `crab-build`**: функция `find_boards(timeout) -> Vec<Found>`: перечисляет сетевые адаптеры
  ПК, шлёт запрос на широковещательный адрес каждого, собирает ответы, убирает дубли по id.
- **`crab-cli`**: команда `find`.
- **`crab-editor`**: кнопка «Найти платы» в диалоге «По сети…», список, подстановка в `[board] host`.
- **Имя и id платы**: проверить, что id по MAC и имя проекта уже есть в `info`; если нет — добавить в `info`
  (общее для USB и сети).
- **Справка**: `help/05-build.md`, «Что нового».

## Риски
- Брандмауэр Windows и VPN-адаптеры: часть адаптеров не отвечает — результат всё равно объединяется.
- Мастер растёт на размер сокета и ответа; нужна проверка ОЗУ на C3.
- Широковещание не работает в сетях с изоляцией клиентов (гостевой Wi-Fi) — сказать в справке.
