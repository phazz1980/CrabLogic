# Задачи: массивы и структуры

Отмечать `[x]` по мере готовности. У каждой задачи — как проверить.

- [x] 1. **Модель данных в `crab-core`:** `ArrayVar`, `StructVar`, формат TOML, предел длины по плате.
  Проверка: тест загрузки/сохранения (круг), старый проект без массивов читается; `cargo test -p crab-core`.
- [x] 2. **Проверка схемы (описание массивов и структур):** вид `array` — имя (общее с переменными), длина (>0, ≤256, на C3 ≤64), начальные значения (число и тип), поля структур. Проверка: тесты `check/arrays.rs`; страница «Массив или структура» в `help/08-errors.md`. Проверки блоков (несуществующий массив или поле, константный индекс вне длины, запись из нескольких мест) — в задаче 3, вместе с блоками.
- [x] 3. **Блоки массивов на чистой логике (симуляция), типы `bool`, `int`, `float`, `byte`, `string`:** встроенные виды `array_get/set/fill/copy/sum/min/max/find/shift/ring/stack` по типу элемента (`crab-core/src/array_blocks.rs`), хранение и поведение в `crab-sim/src/arrays/`, проверки блоков (нет массива, приёмник копирования, константный индекс вне длины, второй записывающий блок — предупреждение (решено 20.11.2026: несколько записывающих разрешены), сумма только для чисел) в `check/arrays.rs`. Проверка: тесты `crab-sim` (`arrays_basic`, `arrays_stats`, `arrays_queue`, модульные), `crab-core`. Не вошло и перенесено: пример скользящего среднего и `docs.md`/справка блоков — в задачу 9; блоки структур — в задачу 3б.
- [ ] 3б. **Блоки структур:** `struct_pack` и `struct_unpack`. Порты зависят от полей структуры, поэтому нужен вид блока, который собирается по определению структуры (как вид по типу массива, но с набором портов из `StructVar.fields`); параметр `struct` с именем. Проверка: тесты ядра (порты по полям, проверка имени и типов) и симуляции (сборка и разбор).
- [x] 4. **Сборка модулей, числовые массивы (`bool`, `int`, `float`, `byte`) одного листа:** область памяти модуля (`wasm/array.rs`), начальная таблица в сегменте данных, все блоки задачи 3 как код WASM, проверка границ индекса, оценка ОЗУ, ошибка «не помещается». Массив, который используют блоки нескольких листов, пока даёт понятную ошибку сборки (общие массивы — задача 5). Проверка: `crab-codegen/tests/library_modules.rs` на каждый блок; тест `crab-sim/tests/wasm_emit.rs`-стиля: модуль и симуляция дают одинаковые выходы и содержимое массива (критерий 3). Сделано: `wasm/array.rs`, `array_stats.rs`, `array_queue.rs`; тесты `crab-sim/tests/wasm_arrays_{basic,stats,queue}.rs` (модуль против симуляции, 4 типа, с проверкой, что выходы меняются) и `crab-codegen/tests/array_modules.rs` (41 блок собирается и валидируется, строки, два листа и переполнение памяти — понятные ошибки). Не проверено на плате (WAMR/AOT): только в тестовом исполнителе на ПК.
