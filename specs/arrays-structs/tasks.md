# Задачи: массивы и структуры

Отмечать `[x]` по мере готовности. У каждой задачи — как проверить.

- [ ] 1. **Модель данных в `crab-core`:** `ArrayVar`, `StructVar`, формат TOML, предел длины по плате.
  Проверка: тест загрузки/сохранения (круг), старый проект без массивов читается; `cargo test -p crab-core`.
- [ ] 2. **Проверка схемы:** несуществующий массив/поле, константный индекс вне длины, запись из нескольких
  мест, предел по плате. Проверка: тесты `check` на каждую ошибку; `crablogic check` на примере с ошибкой.
- [ ] 3. **Блоки на чистой логике (симуляция), типы `bool`, `int`, `float`, `byte`, `string`:** `array_item` (чтение/запись по стороне подключения), `array_fill/copy/sum/min/max/find`, затем `array_shift`,
  `array_stack`, `struct_pack/unpack`; границы индекса. Проверка: тесты `crab-sim`, пример скользящего среднего.
- [ ] 4. **Сборка модулей:** `wasm/array.rs`, область памяти, начальная таблица, оценка ОЗУ, ошибка «не
  помещается». Проверка: `crab-codegen/tests/library_modules.rs` на каждый блок; одинаковый результат с
  симуляцией (критерий 3).
- [ ] 5. **Общие массивы между листами** и вопрос про возможности мастера (`modcaps`). Проверка: тест двух
  листов; решение записано в плане и в архитектуре.
- [ ] 6. ~~`retain` массива~~ — отложено: в первую версию не входит (решение 20.11.2026).
- [ ] 7. **Отладка:** слоты образа, форсировка элемента, нагрузка кадра. Проверка: тест `ImageLayout`;
  онлайн на плате; замер периода опроса.
- [ ] 8. **Редактор:** строки в дереве, диалоги создания, таблица значений, перетаскивание на лист.
  Проверка: тесты форм; ручной просмотр в окне редактора.
- [ ] 9. **Примеры и справка:** `examples/` (скользящее среднее, рецепт-структура, очередь), страница справки,
  `docs.md` блоков, «Что нового», таблица «Чего ещё нет» и архитектура. Проверка: тесты примеров,
  обзор справки.
- [ ] 10. **Замер на платах:** `crablogic bench` на ESP32 и C3, ОЗУ, строка в `bench/history.md`.
- [ ] 11. **Сверка с критериями спеки** (1–6): отметить выполненные и не проверенные на железе.
