# Аналоговый выход (ЦАП)

## Цель

Выдать напряжение 0…3,3 В без ШИМ и RC-фильтра: задание частотнику или регулятору через внешний
усилитель 0–10 В / 4–20 мА, опорное напряжение, проверка аналоговых входов.

## Ограничения железа

- ЦАП есть только у классического ESP32: 2 канала, GPIO25 и GPIO26, 8 бит (шаг ~13 мВ), выход
  слаботочный — нагрузка через повторитель/усилитель.
- У ESP32-C3 ЦАП нет.

## Сценарии

1. Блок «Аналоговый выход» на GPIO25: вход `in` (в первой редакции `value`; имя как у других выходов) — целое 0…255 (код ЦАП, ответ пользователя 14.11.2026;
   вне диапазона — ограничивается); на выводе 0…3,3 В.
2. При аварии модуля (как у «Цифрового выхода» и «ШИМ-выхода») — параметр «при аварии»: 0 В /
   держать / заданное значение.

## Критерии готовности

1. ESP32: напряжение на выводе соответствует входу (замер мультиметром на 3 точках, ±50 мВ).
2. Шаг не ждёт: запись — одно обращение к регистру, без блокировок.
3. Проверка схемы: блок на плате без ЦАП или на другом выводе — понятная ошибка; вывод занят — ошибка.
4. Безопасное состояние при сбое модуля работает (тест: `reset` модуля → 0 В).
5. Тест сборки модуля, пример, `docs.md`, справка, новости.

## Вне задачи

Генератор синуса/косинуса ЦАП (cosine generator), вывод звука, DMA-поток.
