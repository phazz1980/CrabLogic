1. [x] ABI: импорт `dac_write`, `PinUse::Dac`, `Fault::Value(u8)` (биты 16–23), аренда в `host.rs`.
   Проверка: тесты `crab-kernel` (`fault_bits`, таблица импортов).
2. [x] Генератор: `analog_out` в `hardware.rs`, признак `dac`. Проверка: `wasm_emit.rs`
   (`analog_out_clamps_the_code_and_asks_for_the_dac_capability`), сборка модулей библиотеки и примеров.
3. [x] `library/analog_out/block.toml`, `docs.md`. Проверка: тест `analog_out_needs_a_dac_pin` (GPIO4 и C3 —
   ошибка «ЦАП есть только у ESP32: GPIO25 и GPIO26»).
4. [x] Симуляция: поведение, заглушка `dac_out`, напряжение на блоке. Проверка: тест `crab-sim` (`schema.rs`).
5. [x] Мастер: `dac_write` (dac_oneshot), `Hal::safe`, сторож (регистр `RTC_IO_PAD_DACn`), код ЦАП в ответе
   `pins` (`dac=<25>,<26>`), `selftest dac <pin> <code>` (тестовая сборка). Проверка: сборка ESP32 и C3, тесты мастера.
6. [~] Железо ESP32: модуль на COM10 — код 100 на GPIO25 (`pins`: `dac=100`); `del` модуля: «значение» → 50,
   «держать» → 100, «0 В» → 0. `selftest dac` (АЦП2 того же вывода): GPIO25 монотонно 0 → 0,17 В,
   128 → 1,2 В, 255 → 1,98 В — АЦП занижает или нагружает, GPIO26 через АЦП не читается.
   **Не проверено:** напряжение мультиметром (±50 мВ), GPIO26, срабатывание сторожа на выводе ЦАП.
7. [x] Пример `examples/dac_ramp`, справка (сборка, отладка, надёжность, новости, блоки);
   `crablogic bench` ESP32 и C3 — строки 14.11 11:58/12:09 в `bench/history.md`, в пределах шума.

## Сверка 14.11.2026

1. Напряжение ±50 мВ — **не проверено** (нужен мультиметр). Через АЦП того же вывода код растёт монотонно, но
   значения занижены (255 → 1,98 В) — АЦП2 на выводе ЦАП не годится как эталон.
2. Шаг: `dac_oneshot_output_voltage` — короткая критическая секция драйвера; захват вывода (LEDC, GPIO) — только
   при первой записи. Бенч в пределах шума.
3. Проверка схемы: C3 и чужой вывод — ошибка с подсказкой «ЦАП есть только у ESP32: GPIO25 и GPIO26» (тест);
   занятый вывод — общая проверка.
4. Безопасное состояние: `del` модуля → 0 В / держать / значение (проверено на плате по регистру ЦАП).
   Сторож шага пишет код прямо в регистр — **не проверено на выводе** (после срабатывания плата перезагружается).
5. Тест сборки модуля, пример, `docs.md`, справка, новости — есть.
