# Промпт: создать блок для CrabLogic

Прежняя версия этого файла описывала блоки на C++ (`esp32.cpp.tmpl`, `native.cpp`); такие блоки
больше не поддерживаются (удалено 13.11.2026). Актуальное задание для ИИ-агента — навык
`skills/crablogic-block/` (`SKILL.md`, примеры, чек-лист): блок = `block.toml` + `block.wasm` + `docs.md`.
Проверка: `crablogic block check <папка блока>`.
